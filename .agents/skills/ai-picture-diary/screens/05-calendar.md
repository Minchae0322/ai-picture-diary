# 05 감정 캘린더

> 언제: 감정 캘린더 화면(05)을 만들거나 고칠 때. "캘린더", "달력", "월 이동", "날짜 그리드", "이번 달 요약" 언급 시 트리거.

**명세: `docs/screen/05-calendar.md`** (시안 `9:46`).

## 규칙
- 월 집계는 **서버가 계산해 내려준다.** 클라이언트에서 다시 더하면 06과 숫자가 갈린다.
- 주 시작은 일요일 고정(시안 기준).
- 오늘 / 기록 있음 / 기록 없음 / 미래 - 셀 상태 4종을 구분한다. 색만으로 구분하지 않는다.
- 월 이동 시 이전 데이터를 유지한 채 교체한다. 빈 그리드로 깜빡이지 않게.
- 날짜 셀은 터치 타깃 44px 이상. 그리드가 좁다고 줄이지 않는다.

## 이어서 읽을 것
`frontend-state`(월 단위 쿼리 키), `ui-fundamentals`.
