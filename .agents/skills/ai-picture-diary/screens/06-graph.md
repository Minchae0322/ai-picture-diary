# 06 감정 그래프

> 언제: 감정 그래프 화면(06)을 만들거나 고칠 때. "그래프", "기분 추이", "차트", "주/월/년", "KPI", "자주 쓴 말" 언급 시 트리거.

**명세: `docs/screen/06-graph.md`** (시안 `9:181`). 차트 작성 규칙은 `dataviz`를 먼저 읽는다.

## 규칙
- 무기록일은 **선을 끊는다.** 0으로 채우지 않는다 - 0은 "보통"이라는 값이라 거짓이 된다.
- 차트 옆에 텍스트 요약(평균·최고·최저)을 둔다. 차트만으로는 접근성이 안 된다.
- 세그먼트(주/월/년) 전환 시 차트·부제·KPI·단어가 **모두 같은 기간**을 가리켜야 한다.
- 연속 기록 일수는 02·10과 같은 출처. 여기서 따로 세지 않는다.
- 기록 2건 미만이면 추이선을 그리지 않는다.
