# 09 테마 · 캐릭터 상점 (프리미엄)

> 언제: 테마·캐릭터 상점 화면(09, 프리미엄)을 만들거나 고칠 때. "꾸미기", "테마", "캐릭터", "상점", "Jelly Plus", "구독", "인앱결제", "복원" 언급 시 트리거.

**명세: `docs/screen/09-store.md`** (시안 `11:2`).

## 규칙
- 구독 상태의 진실은 **서버가 검증한 영수증**이다. 클라이언트 플래그로 잠금을 풀지 않는다.
- 구독 복원(Restore) 동선이 없으면 iOS 심사에서 막힌다. 시안에 없어도 넣는다.
- 테마는 토큰 재정의로 구현한다(`design-system`). 화면마다 조건 분기 금지.
- 무료 테마는 즉시 적용, Plus는 시트. 잠금 항목을 눌렀을 때 아무 일도 안 일어나게 두지 않는다.
- 배경·폰트 탭은 내용이 미정이다. 빈 탭을 만들지 말고 항목 0개면 탭을 숨긴다.
