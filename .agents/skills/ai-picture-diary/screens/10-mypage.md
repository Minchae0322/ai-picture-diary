# 10 마이페이지

> 언제: 마이페이지 화면(10)을 만들거나 고칠 때. "마이페이지", "MY", "설정", "리마인더", "일기 잠금", "데이터 내보내기", "계정 삭제", "로그아웃" 언급 시 트리거.

**명세: `docs/screen/10-mypage.md`** (시안 `11:87`).

## 규칙
- **계정 삭제가 시안에 없다. 반드시 넣는다** - 두 스토어 모두 필수(`app-store-release`).
- 통계 3종은 서버 집계. 연속 일수는 02·06과 같은 출처를 쓴다.
- 리마인더는 OS 권한 거부 상태를 별도로 표시한다. "매일 오후 9시"라고 써 놓고 안 오는 게 최악이다.
- "AI 그림 스타일"은 생성 프롬프트에 직결된다. 값을 추가할 때 `prompt-and-eval` 절차를 탄다.
- "로컬 우선 저장" 문구를 지키려면 오프라인 작성 + 동기화 충돌 규칙이 필요하다. 규칙 없이 문구만 두지 않는다.
- 설정 행은 현재값을 항상 보여준다. 없으면 "설정 안 함".

## 이어서 읽을 것
`notification`(리마인더), `spring-auth`(계정·삭제), `prompt-and-eval`(그림 스타일).
