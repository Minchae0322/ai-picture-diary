# 용어집

`report-style` 스킬이 분야별로 참조하는 용어 사전. **문체 규칙(SKILL.md)은 분야와 무관하고, 여기만 분야별로 늘어난다.**

| 파일 | 분야 |
|---|---|
| `해운-물류.md` | 해운·물류 (항로, 운임, 할증료, 물동량). **작성 예시를 겸한다** |

이 스킬은 특정 분야 전용이 아니다. 지금 파일이 하나뿐인 것은 그 분야부터 필요했기 때문이고, 새 분야는 아래 절차로 늘린다.

## 새 분야 추가

1. `<분야>.md` 생성
2. 표 형식: `풀어 쓴 말 | 용어 | 영문/약어 | 비고`
3. **출처를 맨 아래에 적는다.** 업계 용어는 회사·지역마다 다르다
4. 확실하지 않은 항목은 `(확인 필요)`로 남긴다. 짐작해서 채우지 않는다
5. "자주 틀리는 것" 절을 둔다 - 비슷해 보이지만 다른 용어 쌍이 어느 분야에나 있다
6. 이 README의 표에 한 줄 추가
