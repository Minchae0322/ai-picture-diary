# 02 홈 · 오늘 기록 전

> 언제: 홈 화면(02, 오늘 기록 전)을 만들거나 고칠 때. "홈", "오늘 한 줄", "기록 입력", "빠른 감정 칩", "연속 기록", "최근 기록" 언급 시 트리거.

**명세: `docs/screen/02-home.md`** (시안 `8:28`). 이 앱의 핵심 입력 화면.

## 규칙
- 홈 탭은 **오늘 기록 유무로 02 또는 04를 렌더**한다. 별도 라우트로 나누지 않는다.
- 입력값은 전송 전에 로컬에 보관한다. 03에서 실패하거나 앱이 죽어도 사용자가 쓴 문장은 잃지 않는다.
- "기록" 전송은 낙관적 전환(03). 실패 시 **입력값을 복원**하고 같은 자리로 돌아온다.
- 연속 기록 일수는 서버 값을 그대로 쓴다. 06·10과 다른 숫자가 나오면 계산이 두 군데 있다는 뜻.
- 최근 기록 0건이면 섹션을 **숨긴다**. 빈 리스트 UI를 만들지 않는다.
- 조회가 실패해도 입력은 살아 있어야 한다. 화면 전체를 에러로 덮지 않는다.
