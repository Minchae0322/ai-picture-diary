# 07 뱃지 컬렉션

> 언제: 뱃지 컬렉션 화면(07)을 만들거나 고칠 때. "뱃지", "업적", "컬렉션", "젤리 7", "연속 달성", "잠금 뱃지" 언급 시 트리거.

**명세: `docs/screen/07-badge.md`** (시안 `10:2`, 12/40개 노출).

## 규칙
- 뱃지 정의(이름·조건 문구·아이콘)는 **서버 마스터 데이터**. 앱에 하드코딩하면 뱃지 추가마다 배포가 필요하다.
- 획득 판정은 서버가 저장 직후 계산한다. 클라이언트 판정 금지.
- "감정 탐험가 · 6종 전부"가 날씨 enum이 6종이라는 유일한 근거다. enum을 바꾸면 이 뱃지 조건도 같이 본다.
- 잠금 뱃지도 조건은 보여준다. 숨기면 동기 부여가 사라진다.
- 시안에 없는 28개를 임의로 만들지 않는다.

## 이어서 읽을 것
