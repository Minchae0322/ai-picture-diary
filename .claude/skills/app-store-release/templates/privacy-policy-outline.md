# 개인정보처리방침 작성 개요 (한국 개인정보보호법 제30조 + 스토어 요구 항목)

웹에 HTTPS 정적 페이지로 게시하고, 앱 설정 화면에서 링크로 연다. 앱 이름, 수집 항목, SDK 목록이 실제와 일치해야 한다.

`{{...}}`를 프로젝트 값으로 채운다. 채울 값은 프로젝트 스킬(`.claude/skills/<제품>/SKILL.md`)에 있다.

## 필수 항목

1. **개인정보의 처리 목적** - 회원 가입/관리, 서비스 제공(`{{제품의 핵심 기능}}`), 고객 문의, 서비스 개선(통계)
2. **수집하는 개인정보 항목과 수집 방법**
   - 필수: 이메일, 닉네임 (소셜 로그인 시 제공자로부터: 이메일, 프로필)
   - 선택: 프로필 사진
   - 자동 수집: 기기 정보, 앱 버전, 크래시 로그, 접속 일시
   - 서비스 이용 중 생성: `{{사용자 생성 콘텐츠. 본문, 첨부, 활동 기록 등}}`
3. **개인정보의 처리 및 보유 기간** - 회원 탈퇴 시 즉시 파기. 법령 보관: 전자상거래법(계약/결제 5년, 소비자 불만 3년), 통신비밀보호법(접속 기록 3개월)
4. **개인정보의 제3자 제공** - 원칙적으로 없음. 있으면 제공받는 자, 목적, 항목, 보유 기간 표
5. **개인정보 처리의 위탁** - 수탁자와 업무 표. 예: `{{클라우드}}`(서버 호스팅), `{{인증/크래시}}`, `{{LLM 제공자}}`(`{{용도}}`, 소재국), `{{소셜 로그인}}`
6. **개인정보의 국외 이전** - 위탁처가 해외면 국가, 이전 항목, 목적, 보유 기간, 이전 일시/방법 명시. **LLM API와 해외 BaaS가 여기 걸린다**
7. **정보주체의 권리·의무와 행사 방법** - 열람, 정정, 삭제, 처리정지 요구. 앱 내 계정 삭제 경로 + 이메일 문의 방법. 만 14세 미만 아동은 법정대리인이 행사
8. **파기 절차 및 방법** - 전자 파일은 복구 불가능한 방법으로 삭제
9. **개인정보의 안전성 확보 조치** - 암호화(비밀번호 해시, 전송 구간 TLS), 접근 권한 관리, 접속 기록 보관
10. **개인정보 보호책임자** - 이름, 직위, 연락처(이메일/전화)
11. **권익 침해 구제 방법** - 개인정보침해신고센터(118), 개인정보분쟁조정위원회, 대검찰청, 경찰청 연락처
12. **개인정보 처리방침 변경** - 시행일, 변경 시 공지 방법
13. **(해당 시) 만 14세 미만 아동** - 가입 제한 또는 법정대리인 동의 절차
14. **(해당 시) 위치정보** - 위치정보의 이용·제공 사실 확인자료 보유 기간, 위치정보 관리책임자
15. **(해당 시) 광고 식별자, 추적** - 광고 ID 수집 여부와 거부 방법

## 스토어 추가 요구

- App Store: 개인정보 라벨(수집 데이터 유형/연결 여부/추적 여부)과 이 문서 내용 일치
- Google Play: 데이터 보안 양식과 일치. **계정 및 데이터 삭제 요청 웹 페이지 URL**을 별도로 제공(이 문서 안의 섹션이어도 되지만 직접 링크 가능해야 함)

## 계정 삭제 안내 페이지 (Google 필수)

- URL 예: https://example.com/account-deletion
- 내용: 앱 내 삭제 경로, 앱 없이 삭제 요청하는 방법(이메일 양식), 삭제되는 데이터와 보관되는 데이터(법령 근거), 처리 기간
