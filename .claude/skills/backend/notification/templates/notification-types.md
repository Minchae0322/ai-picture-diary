# 알림 종류 정의서

이 프로젝트가 보내는 모든 알림. 알림을 추가·변경하면 **같은 PR에서** 이 문서를 고친다.
구분(정보성/광고성)은 법적 요건을 결정하므로 반드시 채운다. 애매하면 광고성으로 둔다.

## 요약

| 코드 | 이름 | 구분 | 채널 | 기본값 | 사용자 끄기 | 사건 키 |
|---|---|---|---|---|---|---|
| `ORDER_CONFIRMED` | 주문 확인 | 정보성 | 푸시, 인앱, 알림톡 | on | 불가 | `order:<id>` |
| `SHIPPING_STARTED` | 배송 시작 | 정보성 | 푸시, 인앱, 알림톡 | on | 가능 | `shipping:<id>` |
| `COMMENT_ADDED` | 내 글에 댓글 | 정보성 | 푸시, 인앱 | on | 가능 | `comment:<id>` |
| `COUPON_ISSUED` | 쿠폰 지급 | **광고성** | 푸시, 인앱 | **off** | 가능 | `coupon:<id>` |
| `RESTOCK_ALERT` | 재입고 알림 | **광고성** | 푸시, 인앱 | **off** | 가능 | `restock:<productId>:<userId>` |

## 광고성 알림 공통 요건

- 사전 수신 동의가 있는 사용자에게만
- 제목 앞에 `(광고)` 표기
- 본문에 전송자 명칭·연락처, 수신거부 방법
- 오후 9시~오전 8시는 야간 수신 동의가 있는 경우만 (없으면 익일 8시로 지연)
- 동의 후 2년마다 재확인 안내

## 상세

### ORDER_CONFIRMED

- **언제**: 주문 결제가 완료된 직후
- **구분**: 정보성 (거래 필수 정보)
- **채널**: 푸시 + 인앱 + 알림톡(푸시 미수신자 대상)
- **템플릿**: `order-confirmed` / 알림톡 템플릿 코드 `<카카오 승인 코드>`
- **변수**: `orderNo`, `productName`, `amount`
- **딥링크**: `app://orders/{orderId}`
- **사건 키**: `order:<orderId>` (중복 방지)
- **실패 정책**: 알림톡 실패 시 SMS 대체발송 **함**
- **비고**: 사용자가 끌 수 없는 알림

### COUPON_ISSUED

- **언제**: 마케팅 대상자에게 쿠폰을 지급했을 때
- **구분**: **광고성** - 수신 동의 확인 필수
- **채널**: 푸시 + 인앱
- **템플릿**: `coupon-issued`
- **변수**: `couponName`, `discountAmount`, `expireDate`
- **제목**: `(광고) ...`로 시작
- **야간**: 금지 (야간 동의자만, 없으면 익일 08:00 지연 발송)
- **사건 키**: `coupon:<couponId>`
- **대량 발송**: 대상 <N>명 초과 시 사람 확인 필요
