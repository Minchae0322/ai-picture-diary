# 프리셋: Muted Sky

## 성격

채도를 낮춘 하늘색 그라디언트 배경 위에 반투명한 흰 카드를 얹는다. 큰 라운드(24~34)와 알약 버튼은 그대로 두되 색이 뒤로 물러나 있어, 화면에 오래 머무는 앱이나 **글과 데이터가 주인공인 화면**에 맞다. 중립축이 회색이 아니라 **청회색(slate)** 이라 색을 거의 안 써도 화면이 차갑게 정돈된다.

쓰면 안 되는 경우: 즉각적인 인상이나 활기가 필요한 화면. 이 프리셋은 일부러 조용해서 판촉·이벤트·게임에는 힘이 부족하다. 그런 화면은 `jelly-peach`처럼 따뜻하고 채도 높은 프리셋을 쓴다.

주 타깃: 모바일 우선. 390x844 기준으로 값을 잡았다.

> 앞선 `jelly-peach`와 **구조는 같고 색만 다르다.** 간격·라운드·그림자·타이포·컴포넌트 규칙은 그대로다.
> 그래서 두 프리셋은 서로 갈아 끼울 수 있다 - 2장의 의미 토큰만 바꾸면 된다.

## 1. 원시값

```css
:root {
  /* 배경 - 위에서 아래로 내려앉는 하늘 */
  --sky-50:  #f4f8fb;   /* 배경 상단 */
  --sky-100: #e8f0f6;   /* 배경 55% 지점 */
  --sky-200: #d8e4ee;   /* 배경 하단 */
  --sky-150: #e2eef7;   /* 카드 그라디언트 끝 */
  --mist:    #eef4f9;   /* 카드 평균 톤. 대비 계산의 기준 배경 */

  /* 청회색 텍스트 계열 - 이 프리셋의 중립축. 순수 회색을 쓰지 않는다 */
  --slate-900: #253544;
  --slate-600: #4e6375;
  --slate-500: #5b6e7f;
  --slate-300: #a8bccd;   /* 장식 전용. 텍스트 금지(5장 참고) */

  /* 브랜드 - 흐린 하늘 */
  --blue-300: #8fbfe0;
  --blue-400: #5b9bc4;   /* 장식 전용 (큰 글리프, 점선, 인디케이터) */
  --blue-600: #3f6d8e;   /* 실제 primary */
  --blue-700: #325a77;

  /* 날씨/악센트 - 전부 한 단계 낮춘 채도 */
  --amber-300:  #e5b877;
  --sand-200:   #dcc9a6;
  --gray-300:   #b6bfc8;
  --steel-300:  #8fa9c8;
  --ice-200:    #cfe0ee;
  --mauve-300:  #c79ab4;
  --violet-300: #a99ac7;
  --sage-300:   #8fbfae;

  --red-600:   #b0434e;
  --amber-700: #8a6a1f;
  --green-700: #1f7a63;

  /* 다크 - 시안에 없어 파생했다(4장) */
  --night-900: #111a21;
  --night-800: #18242d;
  --night-700: #1c2831;
  --night-600: #26343f;
  --night-fg:  #e8f0f6;
  --night-mut: #b3c4d1;
  --night-sub: #8ea1b1;
  --night-on-primary: #0e1a23;
}
```

## 2. 의미 토큰

### 라이트

| 토큰 | 값 | 대비(최악 배경) |
|---|---|---|
| `--color-bg` | 그라디언트 `--sky-50` -> `--sky-100`(55%) -> `--sky-200` | - |
| `--color-surface` | `rgb(255 255 255 / 0.92)` | - |
| `--color-surface-raised` | 그라디언트 `rgb(255 255 255 / 0.85)` -> `rgb(226 238 247 / 0.85)` | - |
| `--color-border` | `rgb(255 255 255 / 0.9)` | - |
| `--color-border-strong` | `#d9e5ee` | - |
| `--color-text` | `var(--slate-900)` | 9.72 |
| `--color-text-muted` | `var(--slate-600)` | 4.83 |
| `--color-text-subtle` | `var(--slate-500)` | 4.76 (표면 위에서만) |
| `--color-primary` | `var(--blue-600)` | 흰 글자 5.54 |
| `--color-primary-hover` | `var(--blue-700)` | 흰 글자 7.33 |
| `--color-primary-fg` | `#ffffff` | - |
| `--color-danger` | `var(--red-600)` | - |
| `--color-warning` | `var(--amber-700)` | - |
| `--color-success` | `var(--green-700)` | - |
| `--color-focus` | `var(--blue-600)` | - |
| `--color-accent-soft` | `var(--blue-400)` | 장식 전용 |

`--color-text-subtle`은 **표면(카드·입력창·탭바) 위에서만** 쓴다. 배경 그라디언트 하단(`--sky-200`) 위에 직접 올리면 3.5로 떨어진다. 배경 위 보조 텍스트는 `--color-text-muted`를 쓴다.

`--color-primary`는 배경 위에서도 4.29:1이라 **큰 글자나 UI 요소로만** 쓴다. 본문 크기의 본문 텍스트를 이 색으로 쓰지 않는다.

### 다크

| 토큰 | 값 |
|---|---|
| `--color-bg` | 그라디언트 `--night-900` -> `--night-800` |
| `--color-surface` | `var(--night-700)` |
| `--color-surface-raised` | `var(--night-600)` |
| `--color-border` | `rgb(255 255 255 / 0.10)` |
| `--color-border-strong` | `rgb(255 255 255 / 0.18)` |
| `--color-text` | `var(--night-fg)` |
| `--color-text-muted` | `var(--night-mut)` |
| `--color-text-subtle` | `var(--night-sub)` |
| `--color-primary` | `var(--blue-300)` |
| `--color-primary-hover` | `#b3d4ec` |
| `--color-primary-fg` | `var(--night-on-primary)` |

다크에서 primary를 `--blue-600`에서 `--blue-300`으로 올리고 전경색을 어두운 감청으로 뒤집는다. 깊이는 그림자가 아니라 명도 차이로 낸다: `bg` < `surface` < `surface-raised`.

## 3. 간격 / 라운드 / 그림자 / 타이포 / 모션

`jelly-peach` 3장과 **같다.** 여기서 반복하지 않는다. 다른 것은 그림자 색뿐이다 - 따뜻한 회갈색 대신 청회색을 섞는다.

```css
:root {
  --shadow-sm: 0 4px 10px rgb(37 53 68 / 0.08);
  --shadow-md: 0 10px 12px rgb(37 53 68 / 0.12);
  --shadow-lg: 0 10px 22px rgb(63 109 142 / 0.32);   /* 주 버튼 전용. 브랜드색 그림자 */
  --shadow-up: 0 -6px 20px rgb(37 53 68 / 0.10);
}
```

## 4. 특징적인 컴포넌트

`jelly-peach` 4장과 같은 모양이고 색만 바뀐다. 다만 이 프리셋에서는 **글로우가 차갑다**: 상단 우측 원형 글로우가 따뜻한 `#ffe0a8`이 아니라 옅은 하늘 `#cde4f5`다. 따뜻한 글로우를 그대로 두면 배경만 하늘색이고 빛만 노란 어색한 화면이 된다.

## 5. 하지 말 것

- 순수 회색(`#888` 같은) 섞기. 중립축은 청회색 `--slate-*`다
- `--slate-300`(#a8bccd)이나 `--blue-400`(#5b9bc4)을 **텍스트 색으로** 쓰기. 둘 다 장식 전용이다(각각 1.5:1, 2.8:1)
- `--color-primary`로 본문 크기 텍스트 쓰기(4.29:1). 큰 글자·버튼·아이콘까지만
- 채도를 되살리려고 악센트 하나만 쨍한 색으로 바꾸기. 조용한 것이 이 프리셋의 목적이다
- 따뜻한 글로우·따뜻한 그림자 남겨두기(4장)
- 불투명 흰 카드. 배경 그라디언트가 비쳐야 성립한다

## 5.5 글래스 예외 (01 온보딩 CTA 한 개)

01 온보딩의 "무료로 시작하기"만 반투명 유리다(`glass-button` 스킬). 나머지 버튼은 전부 solid다.

**이건 프리셋을 섞는 것이 아니라 한 요소에 준 예외다.** design-system 0장이 금지하는 것은
"한 화면에 glass 카드와 soft-modern 카드가 같이 있는" 상태다. 여기서는 앱 전체에서 유리가 한 개,
그것도 탭바가 없는 첫 화면의 히어로 CTA뿐이다.

늘리지 않는다. 두 번째 유리 요소가 필요해지면 그때는 프리셋을 통째로 `clear-glass`나
`glass-depth`로 바꾸는 것이 맞는지 먼저 판단한다.

## 6. 날씨 6종 (이 제품 전용)

`AI 감정 날씨일기`의 날씨색은 배경 톤을 따라간다. 전부 한 단계 낮춘 채도다.

| 날씨 | 값 |
|---|---|
| 맑음 | `--amber-300` `#e5b877` |
| 구름조금 | `--sand-200` `#dcc9a6` |
| 흐림 | `--gray-300` `#b6bfc8` |
| 비 | `--steel-300` `#8fa9c8` |
| 눈 | `--ice-200` `#cfe0ee` |
| 무지개 | `--mauve-300` `#c79ab4` |

**색만으로 날씨를 구분하지 않는다.** 이 6색은 서로 대비가 낮아 색맹 여부와 무관하게 헷갈린다. 라벨이 없는 자리(캘린더 셀, 썸네일)에는 날씨 글리프를 같이 둔다.
