# docs

이 폴더 구조는 `deliverable-structure` 스킬을 따른다. 파일을 놓을 자리는 "특정 도메인 로직인가?"와 "현행인가 이력인가?" 두 질문으로 정한다.

| 폴더 | 성격 | 내용 |
|---|---|---|
| `INDEX.md`, `BOARD.md` | 스킬용 메타 | 현행 문서 매핑, 동기화 상태 |
| `domain/<패키지명>/` | 현행 + 이력 | `<로직>-비즈니스로직.md`, `YYYY-MM-DD-<제목>.md` |
| `guide/` | 현행 | 개발/빌드/배포/환경 가이드 |
| `api/` | 이력 | 외부/프론트 전달 API 명세 |
| `adr/` | 이력 | 설계 결정 기록 |
| `incident/` | 이력 | 장애 분석 |
| `release-notes/` | 이력 | 배포 단위 기록 |
| `ops/` | 현행 | 배치 목록, 로그 정의, 운영 가이드 |
| `erd/` | 현행 | 스키마 |
| `handoff/` | 이력 | 인수인계, 타 팀 전달 |
| `assets/` | 첨부 | 이미지, drawio, pdf |
