# 손으로 그린 UI (hand-drawn-ui)

## 0. 이 스킬은 무엇인가

**장식이 아니라 인터페이스 자체를 손으로 그린다.** 반듯한 화면 위에 낙서를 얹는 것이 아니라,
테두리·버튼·바닥·구분선이 전부 연필과 색연필로 그어진 것처럼 보이게 만든다.

기준으로 삼은 레퍼런스 둘:

| 출처 | 가져온 것 |
|---|---|
| Hand Drawn 디자인 레퍼런스 | 종이 질감, 비대칭 모서리, 살짝 기운 카드, 손글씨 제목 + 읽기 쉬운 본문의 분업 |
| [SketchUI](https://sketchui.sanjoydev.com/) (Rough.js 기반) | 선의 수치(roughness·bowing·strokeWidth), 채우기 방식, 컴포넌트 20종의 구성 |

## 1. 선이 전부다

손그림 UI 의 성패는 색이 아니라 **선**에서 갈린다. 세 가지가 동시에 있어야 손이 그린 선으로 읽힌다.

| # | 성질 | 없으면 | 수치 |
|---|---|---|---|
| 1 | **떨림**(roughness) | 자로 잰 선. 손그림이 아니다 | 기본 `1.4`, 강조 `1.9` |
| 2 | **휨**(bowing) | 직선이 너무 곧다. 사람 손은 긴 직선을 못 긋는다 | `0.8` |
| 3 | **겹쳐 긋기** | **이게 가장 크다.** 한 번에 그은 선은 기계 선이다 | 같은 선을 2번, 둘째는 불투명도 0.4 로 0.5px 어긋나게 |

- 선 굵기 `1.7`, 끝은 둥글게(`stroke-linecap: round`). 각진 끝은 벡터 티가 난다.
- 선 색은 순수 검정(`#000`)이 아니라 **흑연**(`#111` ~ `#3B3B3B`). 연필은 검지 않다.
- **난수는 고정한다.** 리렌더마다 새로 뽑으면 선이 춤춘다 - 손그림이 아니라 고장 난 화면이다.
  자리마다 `seed` 를 주고 그 자리의 선은 늘 같은 모양이게 한다.

### 채우기 (fillStyle)

면을 단색으로 칠하지 않는다. 색연필은 종이 결을 남긴다.

| 값 | 느낌 | 쓰는 곳 |
|---|---|---|
| `hachure` | 한 방향 빗금. **색연필의 기본** | 버튼·뱃지 면 |
| `cross-hatch` | 교차 빗금. 더 진하다 | 강조, 눌린 상태 |
| `zigzag` | 왕복해 칠한 자국 | 넓은 면 |
| `dots` | 점묘 | 연한 강조, 비활성 |
| `solid` | 꽉 찬 면 | 글자가 올라가는 자리(빗금 위 글자는 읽기 어렵다) |

- 빗금 간격 `hachureGap: 5`, 눌렀을 때 `0.75` 로 좁히면 **힘줘 칠한 것처럼** 진해진다.
- **글자 뒤에는 `solid` 를 쓴다.** 가독성이 질감보다 먼저다.

## 2. 색연필 팔레트

종이와 필기구에서 가져온다. 디지털 원색을 쓰지 않는다 - 채도가 높으면 색연필이 아니라 형광등이 된다.

| 역할 | 값 | 비고 |
|---|---|---|
| 종이 | `#FAF6ED` | 스케치북 크림. 순백은 종이가 아니다 |
| 종이(진한 면) | `#F3EBDA` | 섹션 교대, 카드 바닥 |
| 크라프트 | `#E8D5B5` | 띠지, 테이프, 사이드 패널 |
| 종이 그림자 | `#D9CEBC` | 카드 그림자, 구분선 |
| 흑연 | `#3B3B3B` | 본문 글자, 스케치 선 |
| 잉크 | `#2C2825` | 굵은 외곽선, 사인펜 글자 |
| 연한 연필 | `#A09888` | 보조선, placeholder |
| 숯 | `#6B6560` | 보조 글자, 캡션 |
| 수채 파랑 | `#5B9BD5` | 주 강조, 링크 |
| 사인펜 산호 | `#E87461` | 주 행동, 따뜻한 강조 |
| 색연필 초록 | `#6DAE6D` | 성공 |
| 크레용 노랑 | `#F7D55E` | 형광펜, 별 낙서 |
| 분필 라일락 | `#B8A9D4` | 3차 강조, 태그 |
| 펠트펜 주황 | `#E8943A` | 2차 강조 |
| 붓펜 청록 | `#4AADA1` | 정보 |
| 지우개 분홍 | `#F5C6C2` | 연한 강조 바탕, 뱃지 |

SketchUI 의 형광 변형(`#fde047` 노랑 / `#c084fc` 보라 / `#86efac` 초록)은 **더 밝고 장난스럽다.**
어린이·놀이 쪽이면 그쪽, 공책·아틀리에 쪽이면 위 표를 쓴다. **둘을 섞지 않는다.**

## 3. 모양

- **모서리를 네 귀 다르게.** `border-radius: 12px 6px 14px 8px`. 같은 값 네 개면 컴퍼스로 그린 것이다.
- **기울임은 0.5~2.5도.** 그 이상은 취한 화면이다. **누르는 것은 기울이지 않는다** - 클릭 지점이 흔들린다.
- **그림자는 번지지 않고 밀린다.** `2px 3px 0` 같은 **딱딱한 offset 그림자**가 종이 두 장이 겹친 느낌을 만든다.
  블러 그림자는 디지털 티가 난다. 둘을 같이 쓰려면 딱딱한 것을 먼저, 흐린 것을 아주 약하게 뒤에.
- 버튼 기본 180x48, 글자 18, 모서리 12. 누르면 `translateY(-4)` + `rotate(-1deg)`.
- 3D 깊이가 필요하면 `depth: 12`, 각도 `35도`, 옆면은 `#fffbf2` 를 빗금으로 채운다.

## 4. 글자

**제목은 손글씨, 본문은 읽기 쉬운 서체.** 이 분업이 핵심이다 - 손글씨 본문은 세 줄만 넘어가도 피곤하다.

| 자리 | 라틴 | **한글** |
|---|---|---|
| 큰 제목 | Architects Daughter, Fredericka the Great | **Gaegu**, 나눔손글씨 붓 |
| 섹션 제목 | Patrick Hand | **Gaegu**, 나눔손글씨 펜 |
| 주석·말풍선 | Caveat, Indie Flower | **Gamja Flower**, **Poor Story** |
| 강조(사인펜) | Permanent Marker | **Black Han Sans**(굵은 대체), 나눔손글씨 고딕아니고 |
| 본문·UI | Nunito, Quicksand | 기존 고딕 그대로(SUIT, Pretendard 등) |

- **라틴 손글씨 폰트에는 한글 글리프가 없다.** Architects Daughter 로 한글을 쓰면 두부가 뜨거나
  시스템 폰트로 대체된다. 한글 화면이면 **Gaegu 계열을 먼저 고른다.**
- 손글씨는 작은 크기에서 무너진다. **14px 밑으로 내리지 않는다.**
- 밑줄은 직선 대신 **물결 SVG**. 제목 아래 흔들리는 선 하나가 손글씨 티를 크게 올린다.

## 5. 컴포넌트

**구현된 것과 아직 아닌 것을 섞어 적지 않는다.** 목록만 보고 "있다"고 믿으면 쓰려다 없어서 되돌아온다.

### 이 저장소에 실제로 있는 것 (`app/src/shared/ui/`)

| 파일 | 무엇 | 갖춘 것 |
|---|---|---|
| `sketch.ts` | **엔진.** RN 판 rough.js | 떨림·휨·seed, 채우기 6종, 도형 점(둥근 사각·타원·다각형), 변형 색 |
| `SketchShape.tsx` | 도형 하나. 원본의 `rc.path(d, options)` 자리 | 면 -> 채우기(ClipPath) -> 테두리 2번 |
| `SketchBorder.tsx` | 테두리만 | 크기 자동 측정, seed 고정 |
| `SketchButton.tsx` | 버튼 | 채우기 6종, 변형 10종, **3D 두께**(옆면 85도·바닥 -35도), 눌림(roughness 1.4->1.9, 간격 5->0.75), 비활성 |
| `SketchBadge.tsx` | 뱃지 | 모양 4종(사각·둥근사각·타원·원), 변형 10종, 테두리만(transparent) |
| `Tape.tsx` | 마스킹 테이프 | 가장자리 3종(smooth·torn·side-torn), 변형 8종, 기울기·불투명도 |
| `SketchLine.tsx` | 선 한 줄 | 물결 밑줄·구분선. 폭 자동 측정, 진폭·주기·떨림, 겹쳐 긋기 |
| `NotePaper.tsx` | 공책 한 장 | 색연필 괘선(`SketchLine`) + 손그림 테두리 + 테이프. 쓰는 자리 |

- `Card.tsx` 가 `SketchBorder` 를 쓴다 - 앱의 모든 카드가 손그림 테두리다.
- 실제로 그려진 모습은 앱의 `/sketch-gallery` 화면에서 본다.

### 아직 안 만든 것 (설계만. 쓰려면 먼저 만들어야 한다)

바탕 `Paper` `DoodleGridBackground` · 틀 `SectionTitle` ·
행동 `Toggle` `Checkbox` `Combobox` · 알림 `Toast` `Alert` `Tooltip` `HoverCard` ·
조각 `Avatar` `Loader` `Calendar`

수치와 만드는 법은 `reference.md`, 코드 틀은 `components.md` 에 있다. **거기 있는 것은 설계지 구현이 아니다.**

- **`Tape` 가 이 체계의 숨은 주역이다.** 카드 모서리에 붙이면 "종이를 붙여 둔 화면"이 된다.
- **`NotePaper` 의 함정은 간격이다.** 괘선 간격과 글줄 높이(`lineHeight`)가 같은 값이 아니면
  글자가 선 위에 앉지 않고 선을 가로질러 떠다닌다 - 공책이 아니라 줄무늬 상자가 된다.
  그래서 그 값을 컴포넌트 안에 숨기지 않고 호출부와 나눠 갖는다. 쓰인 예: 02 홈(`DiaryComposer`).
- **`Loader` 는 빙글 도는 원을 쓰지 않는다.** 끄적이는 선, 차오르는 빗금이 이 체계의 기다림이다.
  공용 `Loader` 는 아직 없지만 **그렇게 만든 예가 하나 있다**:
  `app/src/features/diary/ui/DrawingBoard.tsx`(03 생성 중). 색연필이 액자 안의 그림을 칠해 나간다 -
  덮개와 연필이 같은 값으로 움직이고, 덮개 경계는 9도 눕혀 손이 쓸고 간 자리로 보이게 했다.

## 6. React Native 에서

Rough.js 는 Canvas/SVG DOM 을 쓰므로 RN 에서 그대로 돌지 않는다. **`react-native-svg` 로 직접 긋는다.**

1. 둘레를 7px 간격으로 점 찍기
2. 각 점을 `±wobble`(1 안팎) 만큼 밀기 - seed 고정 난수
3. 꺾은선이 아니라 **2차 곡선**(`Q`)으로 잇기. 꺾은선은 떨림이 각져 "깨진 선"이 된다
4. 같은 경로를 **두 번** 긋기 - 둘째는 불투명도 0.4, 0.5px 어긋나게

이 저장소의 구현: `app/src/shared/ui/SketchBorder.tsx`.

- 종이 질감은 `feTurbulence` 가 RN 에서 안 되므로 **작은 노이즈 PNG 를 타일로 깐다**(또는 점을 흩뿌린 SVG).
- 빗금 채우기는 `Svg` 안에 평행선 `Line` 여러 개 + `ClipPath`. 간격 5px, 각도 -35도가 기본.
- **기울임·흔들림 애니메이션을 누르는 것에 주지 않는다.** 움직이는 과녁은 못 누른다.

## 7. 하지 말 것

- 손글씨로 본문 쓰기. 제목과 주석까지다
- 난수를 리렌더마다 새로 뽑기 - 선이 춤춘다
- 빗금 위에 글자 얹기 - 읽을 수 없다
- 기울임 3도 넘기기, 누르는 것을 기울이거나 흔들기
- 블러 그림자만 쓰기 - 손그림에는 딱딱한 offset 그림자가 맞는다
- 순수 검정 선·순백 바탕 - 연필은 검지 않고 종이는 희지 않다
- 손글씨 폰트 세 개 이상 섞기
- 반듯한 정원·정사각형. 네 귀가 같은 값이면 컴퍼스로 그린 것이다
- 대비 확인 생략 - 손그림이어도 WCAG AA 는 지킨다
