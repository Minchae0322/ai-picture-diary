# 개조식 보고 문체 - 참고

SKILL.md는 규칙만 담는다. 여기는 실제 변환 예와 판단이 갈리는 지점이다.

## 1. 전체 변환 예

### 원문 (서술형 존댓말)

> 이슬람 최대 명절 중 하나인 라마단이 지난 8월 18일에 끝났습니다.
> 따라서 중동 항로의 거래량과 실재 적재 비율이 다시 늘어날 것으로 보입니다.
> (라마단 직전의 실재 적재 비율은 95%에 육박했습니다).
> 또한 중동 항로 선사협의체에서는 2012년 7월 중 컨테이너 당 300달러의
> 성수기 할증료를 부과할 예정이었으나 이를 유예했습니다.

### 고침

```
중동항로 관련 이슈
라마단(2012.7.20~8.18) 종료에 따라 중동항로 물동량 및 소석률 회복 예상됨.
IRA가 7월 중 적용 예정이던 PSS(USD 300/TEU)를 유예함.
```

### 무엇을 왜 바꿨나

| 원문 | 고침 | 규칙 |
|---|---|---|
| 이슬람 최대 명절 중 하나인 | (삭제) | 6장 - 배경 설명 |
| 지난 8월 18일에 끝났습니다 | 라마단(2012.7.20~8.18) 종료 | 5장 - 괄호 병기, 연도 표기 |
| 따라서 ~ 늘어날 것으로 보입니다 | ~에 따라 ~ 회복 예상됨 | 3장 접속사 제거 + 2장 추정 표시 |
| 거래량 | 물동량 | 4장 - 용어 |
| 실재 적재 비율 | 소석률 | 4장 - 용어 (오타 "실재"도 교정됨) |
| 중동 항로 선사협의체 | IRA | 4장 - 고유 협의체명 |
| 컨테이너 당 300달러의 성수기 할증료 | PSS(USD 300/TEU) | 4장 + 5장 |
| 부과할 예정이었으나 이를 유예했습니다 | 적용 예정이던 ~ 유예함 | 1장 - 종결 |
| 또한 | (삭제, 줄바꿈) | 3장 |

### 판단이 갈린 두 지점

**"소석률 95%"를 지운 것** - 원문은 괄호로 부연했다. 지워도 되는 이유는 앞 문장의 "회복 예상"이 이미 그 근거이기 때문이다. 다만 **95%가 보고의 핵심 수치라면 남긴다.** 숫자는 애매하면 남긴다(6장).

남기는 쪽을 택하면:

```
라마단(2012.7.20~8.18) 종료에 따라 중동항로 물동량 및 소석률 회복 예상됨.
라마단 직전 소석률 95% 수준.
```

**기간 시작일을 채워 넣은 것** - 원문에는 종료일(8.18)만 있었다. 시작일 7.20은 글쓴이가 알고 넣은 것이다. 근거가 있으면 넣어도 되지만, 없으면 이렇게 쓴다.

```
라마단(~2012.8.18) 종료에 따라 ...
```

원문에 없는 정보를 말없이 채우는 것이 요약에서 가장 흔한 사고다(8장 6번).

## 2. 종결어미 표

| 상황 | 쓴다 | 안 쓴다 |
|---|---|---|
| 완료된 행위 | 유예함, 적용함, 종료됨 | 유예했습니다, 유예하였음 |
| 상태 | 검토 중, 미정, 협의 중 | 검토 중에 있음 |
| 전망 | 회복 예상됨, 증가 전망 | 늘어날 것으로 보입니다 |
| 필요 | 확인 필요, 대응 필요 | 확인해야 할 것으로 판단됨 |
| 가능성 | 가능성 있음, ~할 수 있음 | ~할 수도 있을 것 같음 |
| 부정 | 미적용, 미확정, 영향 없음 | 적용되지 않았음 |

`~하였음`, `~있음에 따라`, `~인 것으로 판단됨` 같은 한 단계 늘어난 형태는 쓰지 않는다. 줄이려고 쓰는 문체인데 늘어나면 목적을 잃는다.

## 3. 수치·날짜 표기

| 종류 | 표기 | 안 쓴다 |
|---|---|---|
| 금액(운임·할증) | `USD 300/TEU` | `$300`, `300불`, `컨테이너당 300달러` |
| 원화 | `3,000만원`, `KRW 30M` (문서 내 일관되게) | `삼천만원`, `30,000,000` 혼용 |
| 비율 | `95%` | `95 퍼센트`, `구십오프로` |
| 비율의 변화 | `+3%p` (포인트) / `+3%` (증가율) | 둘을 섞어 쓰기 |
| 날짜 | `2026.9.15` | `26/9/15`, `2026-09-15`와 혼용 |
| 기간 | `2026.9.1~9.15` | `2026.9.1~26.9.15` |
| 월 단위 | `2026.9월 중` | `9월달`, `금월` |
| 범위 불명 | `~2026.8.18` (끝만 확인됨) | 시작을 지어내기 |

**%p와 %를 구분한다.** 소석률이 92%에서 95%가 되면 `+3%p`다. `+3%`는 92 × 1.03 = 94.8을 뜻하게 되어 다른 숫자다.

## 4. 흔한 실수

**존댓말이 섞인다**

```
IRA가 PSS를 유예함.
다만 적용 시점은 추후 공지될 예정입니다.   <- 섞임
```

고침: `다만 적용 시점 추후 공지 예정.`

**추정을 사실로 쓴다**

```
라마단 종료로 물동량이 회복됨.        <- 아직 안 일어났다
```

고침: `라마단 종료에 따라 물동량 회복 예상됨.`

**줄이려다 주체가 사라진다**

```
PSS 유예됨.        <- 누가?
```

고침: `IRA가 PSS를 유예함.` 피동으로 바꾸면 짧아지지만 책임 주체가 사라진다. 보고서에서 "누가"는 대개 지우면 안 되는 정보다.

**불릿이 내용보다 커진다**

```
## 중동항로 관련 이슈
### 물동량
- 라마단 종료에 따라 회복 예상됨.
### 운임
- IRA가 PSS를 유예함.
```

두 줄짜리에 소제목 두 개를 달지 않는다. 항목이 5줄을 넘을 때 묶는다.

**숫자 단위를 빠뜨린다**

```
소석률 95 기록.           <- 95%인가 95만 TEU인가
PSS 300 유예.             <- 통화도 단위도 없다
```

## 5. 용어집

`glossary/<분야>.md`에 둔다. 분야가 늘면 파일을 추가한다. SKILL.md(문체 규칙)는 분야와 무관하게 그대로 쓴다.

현재 있는 파일:

| 파일 | 분야 |
|---|---|
| `glossary/해운-물류.md` | 해운·물류 (항로, 운임, 할증료, 물동량) |

새 분야를 만들 때:

1. `glossary/<분야>.md` 생성
2. 표 형식은 기존 파일과 같게: `풀어 쓴 말 | 용어 | 영문/약어 | 비고`
3. **출처를 적는다.** 업계 용어는 회사·지역마다 다르게 쓰이는 것이 있다
4. 확실하지 않은 항목은 `(확인 필요)`로 남긴다. 지우거나 짐작해서 채우지 않는다

## 6. 다른 스킬과의 관계

| 하려는 일 | 스킬 |
|---|---|
| `docs/` 폴더 구조, 문서를 어디에 둘지 | `deliverable-structure` |
| 도메인 비즈니스 로직 문서의 **내용** 작성 | `deliverable-write` |
| 코드 변경 후 문서 동기화 | `deliverable-sync` |
| 장애 보고서의 **절차** | `rca-procedure` |

이 스킬은 **문체**만 다룬다. 무엇을 쓸지는 위 스킬들이, 어떻게 쓸지는 이 스킬이 정한다.
