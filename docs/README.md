# AI 감정 날씨일기

하루에 한 줄만 적으면 AI가 그 문장의 감정을 읽어 **날씨로 판정하고 그림으로 그려 주는** 모바일 일기 앱.
쌓인 날씨는 달력과 그래프가 되고, 연속 기록은 젤리 뱃지가 된다.

> 갱신: 2026-09-22 · 시안 **10화면 전부** 동작한다. 단 로그인·결제·댓글이 없고 커뮤니티 신고 처리 도구가 없다.

## 기능

| 기능 | 상태 | 설명 |
|---|---|---|
| [온보딩](feature/온보딩.md) | 동작함 | 첫 실행 3장 안내 |
| [오늘 한 줄 기록](feature/오늘-한줄-기록.md) | 동작함 | 한 줄 -> 감정 날씨 판정 -> 그림 -> 다시 그리기 |
| [감정 캘린더와 그래프](feature/감정-캘린더와-그래프.md) | 동작함 | 달력의 날씨, 기분 추이, 연속 기록, 자주 쓴 말 |
| [뱃지 컬렉션](feature/뱃지-컬렉션.md) | 동작함(일부 잠김) | 12종 정의. 댓글·구독 뱃지는 해당 기능이 없어 잠김 |
| [커뮤니티 피드](feature/커뮤니티-피드.md) | 동작함(주의) | 공유·좋아요·신고. **신고 처리 도구가 없다** |
| [프로필과 꾸미기](feature/프로필과-꾸미기.md) | 동작함(일부만) | 테마·캐릭터 선택, 통계. 결제·계정 삭제 없음 |
| 로그인 | 없음 | 계정이 없다. 임시 사용자 한 명으로 동작 |
| 댓글 | 없음 | 커뮤니티 댓글 수는 항상 0 |
| 구독 결제 | 없음 | Jelly Plus 항목은 아무도 쓸 수 없다 |

화면 단위의 자세한 진행 상황은 [BOARD.md](BOARD.md).

## 문서 찾기

| 무엇이 궁금한가 | 어디 |
|---|---|
| 이 앱이 무슨 기능을 하나 | `feature/` |
| 무엇이 어디까지 됐나 | `BOARD.md` |
| 화면이 어떻게 생겼고 무엇을 하나 | `screen/` |
| 동작 규칙과 상태 변화 | `domain/<도메인>/` |
| 실행 방법, 공통 응답·에러 규약, 로그 | `guide/개발-가이드.md` |
| API를 어떻게 호출하나 | `api/` |
| 테이블이 어떻게 생겼나 | `db/` (SQL은 `sql/patch/`) |
| 문서 <-> 코드 매핑 | `INDEX.md` |

구조 규칙은 `deliverable-structure`, 화면 문서 규칙은 `.claude/skills/ai-picture-diary/screens/README.md`.
