# AI 감정 날씨일기

하루에 한 줄만 적으면 AI가 그 문장의 감정을 읽어 **날씨로 판정하고 그림으로 그려 주는** 모바일 일기 앱.
쌓인 날씨는 달력과 그래프가 되고, 연속 기록은 젤리 뱃지가 된다.

> 갱신: 2026-09-21 · 시안 10화면이 **모두 있다.** 그중 3화면만 실제 데이터로 동작하고 나머지는 예시 값이다.

## 기능

| 기능 | 상태 | 설명 |
|---|---|---|
| [오늘 한 줄 기록](feature/오늘-한줄-기록.md) | 동작함 | 한 줄 -> 감정 날씨 판정 -> 그림 -> 다시 그리기 |
| [화면 10종 (시안 그대로)](feature/화면-10종-시안-구현.md) | 화면만 | 시안 10화면이 다 있다. 아래 6개의 숫자는 아직 예시 값이다 |
| 감정 캘린더 | 화면만 | 달력에 하루하루의 날씨 |
| 감정 그래프 | 화면만 | 기분 추이, 자주 쓴 말 |
| 뱃지 컬렉션 | 화면만 | 연속 기록으로 모으는 뱃지 40종 |
| 커뮤니티 | 화면만 | 오늘의 날씨 피드, 좋아요·신고 |
| 테마 상점 | 화면만 | 구독, 테마와 캐릭터 |
| 마이페이지 | 화면만 | 알림 설정, 일기 잠금, 내보내기, 계정 삭제 |
| 로그인 | 없음 | 계정이 없다. 임시 사용자 한 명으로 동작 |

화면 단위의 자세한 진행 상황은 [BOARD.md](BOARD.md).

## 문서 찾기

| 무엇이 궁금한가 | 어디 |
|---|---|
| 이 앱이 무슨 기능을 하나 | `feature/` |

| 테이블이 어떻게 생겼나 | `db/` (SQL은 `sql/patch/`) |
| 문서 <-> 코드 매핑 | `INDEX.md` |

구조 규칙은 `deliverable-structure`, 화면 문서 규칙은 `.claude/skills/ai-picture-diary/screens/README.md`.
