# AI 감정 날씨일기

하루에 한 줄만 적으면 AI가 그 문장의 감정을 읽어 **감정 9종으로 판정하고 그림으로 그려 주는** 모바일 일기 앱.
쌓인 감정은 달력과 그래프가 되고, 연속 기록은 젤리 뱃지가 된다.

(이름의 "날씨"는 시안에서 온 것이다. 2026-10-19 에 표현을 날씨 6종에서 감정 9종 과일 캐릭터로 바꿨다.)

> 갱신: 2026-10-19 · 시안 **10화면 전부 + 11 로그인 화면**이 동작한다. 단 로그인은 화면만 있고(인증 없음) 결제·댓글이 없으며 커뮤니티 신고 처리 도구가 없다.

## 기능

| 기능 | 상태 | 설명 |
|---|---|---|
| [온보딩](feature/온보딩.md) | 동작함 | 첫 실행 3장 안내 |
| [오늘 한 줄 기록](feature/오늘-한줄-기록.md) | 동작함 | 오늘의 기분(필수) -> 공책에 200자 -> 감정 9종 판정 -> 그림 -> 다시 그리기 |
| [감정 캘린더와 그래프](feature/감정-캘린더와-그래프.md) | 동작함 | 달력의 감정 캐릭터, 기분 추이, 연속 기록, 자주 쓴 말 |
| [뱃지 컬렉션](feature/뱃지-컬렉션.md) | 동작함(일부 잠김) | 12종 정의. 댓글·구독 뱃지는 해당 기능이 없어 잠김 |
| [커뮤니티 피드](feature/커뮤니티-피드.md) | 동작함(주의) | 공유·좋아요·신고. **신고 처리 도구가 없다** |
| [프로필과 꾸미기](feature/프로필과-꾸미기.md) | 동작함(일부만) | 테마·캐릭터 선택, 통계. 결제·계정 삭제 없음 |
| [로그인 없이 쓰기](feature/로그인-없이-쓰기.md) | 동작함 | 계정 없이 기기 번호로 쓴다. 핵심 루프는 열리고 07·08·09·10은 로그인 벽 |
| 로그인 | 화면만 | 11 화면과 로그인 시트는 있으나 누르면 "인증이 아직 붙지 않았어요". 시트의 "그냥 둘러보기"가 임시 통로 |
| 댓글 | 없음 | 커뮤니티 댓글 수는 항상 0 |
| 구독 결제 | 없음 | Jelly Plus 항목은 아무도 쓸 수 없다 |

화면 단위의 자세한 진행 상황은 [BOARD.md](BOARD.md).

## 문서 찾기
