# ADR: 로컬 DB 에 한해 AI 의 SQL 실행을 허용한다

- 날짜: 2026-10-24
- 상태: 채택
- 범위: `CLAUDE.md` "즉시 금지", 프로젝트 스킬 5장, `db-schema-and-migration` 적용 방식

## 배경

지금까지의 규칙은 **"어떤 환경이든 DB 접속·SQL 실행 금지"** 였다. 스키마 변경은 `sql/patch/*.sql`
파일과 `docs/db/` 문서로만 남기고, 실행은 늘 사람이 했다.

그 규칙이 막으려던 것은 분명하다 - **되돌릴 수 없는 파괴**다. 운영 DB 에 `DROP`/`UPDATE` 가
잘못 나가면 복구가 백업 복원이고, 마이그레이션은 한 번 어긋나면 그 뒤의 모든 패치가 어긋난다.

그런데 이 규칙이 실제로 만든 결과는 다른 쪽이었다.

1. **패치 7 개가 어디에도 실행된 적이 없다.** 2026-10-14 MySQL 전환, 2026-10-19 감정 전환,
   2026-10-20 게스트 모드까지 전부 파일로만 존재한다. `ddl-auto: validate` 라 백엔드가 기동하지 않는다.
2. **그래서 앱을 끝까지 확인할 수 없다.** 2026-10-24 에 바탕 네 겹을 넣고 시뮬레이터로 확인하려 했을 때
   `AccountGate` 에서 막혔다 - 기기 등록이 실패해 `Backdrop` 이 있는 화면에 도달조차 못 했다.
   바탕 겹 둘이 **아예 안 그려지고 있던 버그**는 게이트를 임시로 통과시킨 뒤에야 발견됐다.
3. **검증되지 않은 DDL 이 쌓인다.** `ddl-auto: validate` 와 실제 DDL 이 맞는지는 올려 봐야 안다.
   올릴 수 없으니 7 개가 전부 미검증 상태로 누적됐다.

규칙이 파괴를 막은 것이 아니라 **검증을 막고 있었다.** 로컬 개발 DB 는 언제든 버리고 다시 만들 수 있는
것이라 애초에 이 규칙이 지키려던 자산이 아니다.

## 결정

**로컬 개발 DB 에 한해 AI 의 접속과 SQL 실행을 허용한다.**

허용 조건은 셋이고, 하나라도 어긋나면 금지가 그대로다.

| 조건 | 내용 |
|---|---|
| 호스트 | `localhost` / `127.0.0.1` 만. 원격 호스트명이 보이면 중단한다 |
| 스키마 | `jellydiary` 하나. 다른 스키마는 건드리지 않는다 |
| 계정 | `application-local.yml` 의 `jelly` 계정. **root 로 붙지 않는다** |

- 실행하는 것은 **`sql/patch/*.sql` 에 이미 있는 파일**과 확인용 읽기 쿼리(`SELECT`, `SHOW`, `DESCRIBE`)다.
  그 자리에서 지어낸 DDL/DML 을 날리지 않는다 - 스키마의 진실은 여전히 `sql/patch/` 파일이다.
- 실행한 뒤에는 해당 `docs/db/*.md` 의 **실행 기록을 채운다.** 실행하고 적지 않으면
  파일만 보던 때보다 상태가 더 불투명해진다.

## 그래도 바뀌지 않는 것

- **운영·스테이징 DB 는 여전히 절대 금지다.** 사람이 한다. 이 ADR 은 로컬만 연다.
- **스키마 변경의 출발점은 여전히 파일이다.** `sql/patch/*.sql` 을 쓰고 `docs/db/` 에 문서를 쓴 다음
  실행한다. 순서를 뒤집어 DB 를 먼저 고치고 파일을 나중에 맞추지 않는다.
- `ddl-auto` 는 `validate` 그대로다. 하이버네이트가 스키마를 만들게 두지 않는다.
- 데이터를 지우는 쿼리(`DROP`, `TRUNCATE`, `DELETE`)는 로컬이어도 **먼저 말하고 실행한다.**
  로컬이라 안전한 것은 "되돌릴 수 있다"는 뜻이지 "말없이 해도 된다"는 뜻이 아니다.

## 근거

- 로컬 DB 는 버리고 다시 만들 수 있다. 규칙이 지키려던 자산이 아니다.
- 실행해 보지 않은 마이그레이션은 **검증된 적 없는 코드**와 같다. 7 개가 쌓인 지금이 그 증거다.
- 2026-10-24 의 경험: 눈으로 보고 "되는 것 같다"로 끝낸 변경에 버그가 둘 있었다. 끝까지 띄워 보는 것이
  문서를 한 장 더 쓰는 것보다 많이 잡는다.

## 되돌리는 법

`CLAUDE.md` 와 프로젝트 스킬 5장의 문장을 원래대로(`어떤 환경이든 ... 금지`) 되돌리면 된다.
코드가 아니라 규칙이라 되돌리는 비용이 거의 없다.
