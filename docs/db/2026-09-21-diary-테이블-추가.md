> 2026-09-21 · DB 변경 · SQL `sql/patch/2026-09-21-diary-테이블-추가.sql`

## 무엇을
그림일기 핵심 루프(02 기록 -> 03 생성 -> 04 결과)를 담을 `tb_diary` 1개와 시퀀스 `seq_diary` 추가.

## 왜
일기 본문·AI 판정(날씨/점수/코멘트)·그림 URL·생성 상태를 한 행으로 관리. 하루 1건 규칙을 DB 제약으로 보장.

## 영향
- 신규 테이블. 기존 데이터 영향 없음. 예상 행 수 = 사용자 수 x 일수.
- 애플리케이션은 `ddl-auto: validate`라 이 SQL이 먼저 실행돼야 기동된다.

## 실행 순서
1. 개발 DB에 SQL 실행 (담당: 개발자)
2. 애플리케이션 기동 확인 (`validate` 통과 = 매핑 일치)
3. 운영은 최초 배포 시 동일 순서
