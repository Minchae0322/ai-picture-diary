선

색이 아니라 선에서 갈립니다. 셋이 동시에 있어야 손이 그린 선으로 읽힙니다.

떨림 + 휨 + 겹쳐 긋기

가장 큰 것은 겹쳐 긋기입니다. 사람은 한 번에 선을 못 맞춰 두 번 긋습니다. 이게 없으면 아무리 떨어도 기계가 흉내 낸 선으로 보입니다.

roughness 1.4 (강조 1.9)bowing 0.8strokeWidth 1.7 stroke #111 (순수 검정 아님)linecap round2번 긋기, 둘째 opacity .4 
// RN - 구현 전체는 app/src/shared/ui/SketchBorder.tsx
<SketchBorder radius={24} color={colors.border} strokeWidth={1.7} seed={7} />

// seed 는 자리마다 다르게. 같은 수면 네 귀가 똑같이 떨려 도장 찍은 티가 난다

채우기 - 색연필은 종이 결을 남긴다

면을 단색으로 칠하지 않습니다. 다만 글자 뒤에는 빗금을 쓰지 않습니다 - 읽을 수 없습니다.

hachure - 기본cross-hatch - 강조, 눌림dots - 연한 강조, 비활성간격 5px, 각도 -35도누르면 간격 0.75 로
// 평행선 + ClipPath. 코드 전체는 skills/hand-drawn-ui/components.md
<Hatch width={w} height={h} radius={18} color={colors.primary} gap={5} angle={-35} />

틀 4

Card · SketchBorder · Separator · SectionTitle

Card

네 귀를 다르게, 0.5~2.5도 기울임, 딱딱한 그림자. 셋이 모이면 "놓아둔 종이"가 됩니다.

오늘의 기분

평균 +1.5 · 2일 연속

테이프로 붙인 카드

위 귀에 하나만 붙여도 됩니다

radius 18 (네 귀 다르게)padding 24그림자 2px 3px 0기울임 -1.2도
<Card seed={11}>
  <Heading>오늘의 기분</Heading>
</Card>

// 네 귀를 다르게
contentStyle={{ borderTopLeftRadius:26, borderTopRightRadius:18,
                borderBottomRightRadius:28, borderBottomLeftRadius:20 }}

Separator

직선 구분선을 쓰지 않습니다. 물결 하나로 손그림 티가 크게 올라갑니다.

<Separator width={320} color={colors.decor} />
// 밑줄로 쓸 때는 제목 폭의 55~60%만. 다 그으면 구분선이 된다

행동 4

Button · Toggle · Checkbox · Combobox

Button

면은 solid, 테두리만 거칠게. 빗금 위 글자는 못 읽습니다. 웹의 hover 회전은 모바일에서 누름 1px 로 받습니다 - 움직이는 과녁은 못 누릅니다.

height 48 (터치 44 이상)radius 24/10/22/12그림자 2px 3px 0 ink누르면 translateY 1
<Pressable style={({pressed}) => [{
  height:48, paddingHorizontal:24, borderRadius:24,
  backgroundColor: pressed ? colors.primaryPressed : colors.primary,
  transform:[{ translateY: pressed ? 1 : 0 }],
}]}>
  <Text>{label}</Text>
  <SketchBorder radius={24} color={colors.text} seed={3} />
</Pressable>

Toggle · Checkbox

손잡이는 정원이 아니라 찌그러진 원. 체크는 폰트 글리프가 아니라 두 획으로 그은 V.

<Path d="M4 11 L9 16 L18 5" stroke={colors.primary}
      strokeWidth={2.4} strokeLinecap="round" fill="none" />

조각 5

Badge · Tape · Avatar · Loader · Calendar

Tape - 숨은 주역

가장 값싸고 효과가 큽니다. 카드 위 귀에 하나 붙이면 화면이 "붙여 둔 종이"가 됩니다.

행복한 2일 연속 획득 추천 인기
젤
테이프 폭 60~90, 불투명도 .75기울기 -6 ~ +6도뱃지 네 귀 10/4/8/4아바타는 찌그러진 원
<Tape color={colors.kraft} width={76} angle={-5} />
// 불투명도 0.75 - 밑이 비쳐야 테이프다

Loader

빙글 도는 원을 쓰지 않습니다. 끄적이는 획, 차오르는 빗금이 이 체계의 기다림입니다.

하지 말 것

하지 말 것왜
손글씨로 본문 쓰기세 줄만 넘어도 피곤하다. 제목과 주석까지
난수를 매 렌더 새로 뽑기선이 춤춘다. 손그림이 아니라 고장 난 화면
빗금 위에 글자읽을 수 없다. 글자 자리는 solid
누르는 것을 기울이거나 흔들기움직이는 과녁은 못 누른다
블러 그림자만 쓰기종이는 번지지 않고 밀린다. 딱딱한 offset
순수 검정 선, 순백 바탕연필은 검지 않고 종이는 희지 않다
기울임 3도 넘기기취한 화면이 된다. 0.5~2.5도
네 귀 같은 radius컴퍼스로 그린 티가 난다
대비 확인 생략손그림이어도 WCAG AA 는 지킨다
