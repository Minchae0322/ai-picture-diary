# 프로필과 꾸미기

> 기능 소개 (비개발자용) · 상태: 동작함(일부만) · 화면 09·10 · 갱신: 2026-09-22

## 무엇을 하는 기능인가

내 기록이 얼마나 쌓였는지 보고, **테마와 캐릭터로 앱을 꾸민다.**

## 사용자가 하는 일

1. **내 정보 보기** - MY 탭에서 닉네임·캐릭터·가입일과 총 기록 수, 연속 일수, 뱃지 수를 본다.
2. **꾸미기** - "테마 변경"에서 테마 4종과 캐릭터 4종을 고른다. 무료 항목은 누르면 바로 적용된다.
3. **일기 잠금 켜기/끄기** - 설정 목록에서 누르면 바뀐다.
4. **뱃지 보러 가기** - 설정 목록의 "뱃지"에서 07 화면으로 간다.

## 규칙

가입하면 **"말랑한 젤리곰" 같은 별명이 자동으로 붙는다.** 마음에 안 들면 바꿀 수 있고, 남과 겹쳐도 된다.

| 항목 | 값 |
|---|---|
| 무료 테마 | Jelly(기본), Mint Soda |
| Plus 전용 테마 | Night Jelly, Lavender |
| 무료 캐릭터 | 젤리곰(기본) |
| Plus 전용 캐릭터 | 별사탕, 구름이, 새싹 |
| 적용 중 표시 | 한 번에 하나 |

구독 여부는 **서버가 가진 값만** 믿는다. 앱에서 바꿀 수 없다.

## 예외 상황에서 어떻게 보이나

| 상황 | 사용자에게 |
|---|---|
| Plus 전용을 눌렀다 | "OOO은 구독하면 쓸 수 있어요" |
| 구독 버튼을 눌렀다 | "결제는 아직 준비 중이에요" |
| 통계 조회가 실패했다 | 숫자 자리에 "-" |
| 아직 준비 안 된 설정을 눌렀다 | "아직 준비 중이에요" |

## 아직 이런 점이 있다

> [!WARNING]
> **계정 삭제가 없다.** 앱스토어·플레이스토어 모두 필수 항목이라 로그인 기능과 함께 반드시 붙여야 한다.

> [!NOTE]
> - 구독 결제가 없다. Plus 항목은 아무도 쓸 수 없다. 구독 복원(iOS 심사 필수) 동선도 없다.
> - 리마인더 알림은 **값만 저장된다.** 실제로 알림이 오지 않는다.
> - "AI 그림 스타일"도 값만 저장되고 그림 생성에 아직 반영되지 않는다.
> - "일기 잠금"을 켜도 실제 잠금(지문·PIN)이 걸리지 않는다.
> - 데이터 내보내기, 로그아웃은 준비 중이다.
> - 시안의 "배경"·"폰트" 카테고리는 내용이 없어 탭 자체를 보여주지 않는다.
