# 화면 10종 (시안 그대로)

> 갱신: 2026-09-21 · 시안: [AI 감정 날씨일기 · Web App Sketch](https://www.figma.com/design/zbYEQIRk1ttPOFzojh2hcL/AI-%25EA%25B0%2590%25EC%25A0%2595-%25EB%2582%25A0%25EC%2094%25A8%25EC%259D%25BC%25EA%25B8%25B0---Web-App-Sketch?node-id=2-7)

## 무엇인가

앱의 화면 10개를 디자인 시안대로 다 만들었다. 지금까지는 "오늘 한 줄 기록"에 해당하는 3화면만 있었고
나머지는 "다음 라운드에 붙습니다"라는 안내만 있었다.

## 사용자가 하는 일

| 화면 | 할 수 있는 일 |
|---|---|
| 온보딩 | 앱을 처음 켜면 한 번 본다. "무료로 시작하기"를 누르면 다시 나오지 않는다 |
| 홈 | 오늘 한 줄을 쓰고, 기분을 칩으로 고르고, 최근 3일을 본다 |
| 생성 중 | 쓴 문장 위로 AI가 그리는 동안의 대기 화면이 덮인다 |
| 결과 | 그림, 날씨 판정, AI 코멘트를 보고 다시 그리거나 공유한다 |
| 캘린더 | 한 달치 날씨를 달력으로 본다. 달을 앞뒤로 넘긴다 |
| 그래프 | 주/월/년으로 기분 추이와 요약 수치를 본다 |
| 뱃지 | 모은 뱃지와 아직 못 모은 뱃지의 조건을 본다 |
| 커뮤니티 | 다른 사람의 오늘 날씨를 구경하고 좋아요를 누른다. 신고·차단도 여기서 한다 |
| 꾸미기 | 테마와 캐릭터를 고른다. Plus 항목은 구독 안내가 뜬다 |
| 마이페이지 | 프로필과 누적 기록을 보고 설정으로 들어간다 |

## 규칙

- **하루에 한 줄, 하루에 한 건.** 같은 날 두 번 쓸 수 없다.
- 본문은 1~500자. 450자부터 남은 글자 수가 보인다.
- 기분 점수는 -3 ~ +3. 결과 화면과 그래프가 같은 범위를 쓴다.
- 날씨는 6종 고정: 맑음 / 구름조금 / 흐림 / 비 / 눈 / 무지개.
- **날씨를 색으로만 보여주지 않는다.** 달력 칸과 썸네일에는 날씨 그림도 같이 들어간다.
  시안의 날씨색끼리는 눈으로 구분이 잘 되지 않아서다.
- 저장 버튼을 누를 필요가 없다. 그림이 만들어지는 순간 이미 저장돼 있다.
- "AI generated" 표시는 지우지 않는다.

## 예외 화면

- **기록이 없는 달**: 달력은 그대로 두고 요약 자리에만 "이 달은 아직 기록이 없어요".
- **기록 3일 미만**: 그래프는 선을 그리지 않고 "기록이 3일 이상 쌓이면 추이를 보여드려요".
- **기록이 없는 날**: 달력 칸이 점선 원으로 비어 있고 눌리지 않는다.
- **그림 생성 실패**: 그림 자리에 "그림을 만들지 못했어요" + 다시 그리기. 글로 된 결과는 그대로 보인다.
- **필터 결과 0건**: 커뮤니티에 "이 날씨의 기록이 아직 없어요" + 필터 해제 버튼.

## 한계 (지금은 이렇게 동작한다)

- **캘린더·그래프·뱃지·커뮤니티·꾸미기·마이페이지의 숫자는 가짜다.** 화면은 시안대로 동작하지만
  서버에 해당 기능이 아직 없어서 정해진 예시 값을 보여준다. 실제 기록과 연결돼 있지 않다.
- 로그인이 없다. 닉네임 "승희"도 예시 값이다.
- 연속 기록 일수(14일)도 예시 값이다. 실제로 며칠 썼는지와 무관하다.
- 생성 중 화면의 진행 막대는 **몇 퍼센트인지 알려주지 않는다.** 서버가 단계를 알려주지 않아
  진행률을 지어내지 않기로 했다. 대신 왕복하는 막대로 "일하는 중"만 보여준다.
- 커뮤니티의 신고·차단은 눌리지만 아직 아무 데도 접수되지 않는다.
- 테마를 골라도 앱 색이 바뀌지 않는다. 구독 결제도 붙어 있지 않다.
- 설정 6개 항목은 눌러도 안내만 뜬다.
- 과거 날짜를 눌러 그날의 기록을 다시 보는 화면이 아직 없다.

자세한 화면별 내용은 `docs/screen/`, 무엇이 어디까지 됐는지는 `docs/BOARD.md`.
