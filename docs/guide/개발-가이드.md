# 개발 가이드

> 도메인 무관 현행 문서 · 코드: `api/src/main/java/com/jellydiary/common/**`, `api/src/main/resources/**`, `app/src/shared/**` · 갱신: 2026-09-21

## 1. 실행

| 대상 | 명령 | 선행 조건 |
|---|---|---|
| 스키마 | `psql -f sql/patch/2026-09-21-diary-테이블-추가.sql` | 사람이 실행. AI는 DB에 접속하지 않는다 |
| 서버 | `cd api && gradle wrapper` (최초 1회) -> `./gradlew bootRun` | JDK 21, PostgreSQL |
| 서버 테스트 | `./gradlew test` (단위+ArchUnit) / `./gradlew integrationTest` (Docker 필요) | |
| 앱 | `cd app && npm install && npx expo install --fix && npm run start` | Node 20+, `app/INSTALL.md` |

환경변수는 `api/.env.example`, `app/.env.example`. 기본 프로파일은 `local`이며 `application-local.yml`의 값으로 뜬다.

## 2. 서버 공통 계약

프론트가 의존하는 부분이다. 바꾸면 앱의 `shared/api`도 같이 바뀐다.

| 항목 | 규칙 | 코드 |
|---|---|---|
| 성공 응답 | `{ "data": ..., "meta": { "traceId" } }` | `common/response/ApiResponse` |
| 목록 응답 | `meta`에 `nextCursor`, `hasNext` 추가. 커서 페이징 고정 | `common/response/Meta` |
| 실패 응답 | `{ "error": { "code", "message", "errors?" }, "meta": { "traceId" } }` | `common/error/ErrorResponse` |
| 에러 코드 | `ErrorCode` enum 한 곳이 코드·HTTP 상태·기본 메시지를 소유 | `common/error/ErrorCode` |
| 예외 변환 | `@RestControllerAdvice` 한 곳에서만 | `common/error/GlobalExceptionHandler` |
| 도메인 예외 | 거절은 도메인이 `BusinessException(ErrorCode.XXX)`로 **직접** 던진다. 서비스가 `IllegalArgumentException`을 잡아 번역하지 않는다 | `api-design` 3장 |
| 시스템 예외 | 어댑터 계약 위반·설정값 오류처럼 사용자가 만들 수 없는 상황은 `IllegalArgumentException`(5xx). 4xx와 섞지 않는다 | `spring-code-review` |
| 인증 | **임시.** `X-User-Id` 헤더 -> `@LoginUser Long` 파라미터. 없으면 401 | `common/auth/**` |
| 시각 | 저장은 UTC(`timestamptz`), 날짜 경계 판단은 Asia/Seoul. `Clock` 빈이 이 존으로 고정된다 | `app.timezone` |
| 업무 상한 | 코드 상수로 박지 않는다. `app.<도메인>.*` -> `XxxPolicy` 값 객체로 도메인에 넘긴다. DDL과 같은 값(컬럼 길이)만 엔티티의 `*_COLUMN_LENGTH` 상수 | `app.diary.*`, `app.profile.*` |

상태 코드 매핑

| 상황 | 코드 | ErrorCode |
|---|---|---|
| 검증 실패 | 400 | `COMMON_INVALID_REQUEST` (+ `errors[]`) |
| 인증 없음 | 401 | `COMMON_UNAUTHORIZED` |
| 없음 / 남의 리소스 | 404 | `<도메인>_NOT_FOUND` |
| 중복 생성, 낙관 락 충돌 | 409 | `<도메인>_ALREADY_EXISTS`, `COMMON_CONFLICT` |
| 비즈니스 규칙 위반 | 422 | `<도메인>_<사유>` |

> [!IMPORTANT]
> 인증은 임시 구현이다. `spring-auth` 도입 시 `CurrentUser`, `CurrentUserFilter`, `X-User-Id`는 삭제하고 `LoginUserArgumentResolver`만 SecurityContext 기반으로 바꾼다. 앱의 `shared/api/httpClient.ts`의 헤더도 같이 사라진다.

## 3. 관측성

| 항목 | 내용 |
|---|---|
| 로그 형식 | `local`은 사람용 패턴, 그 외 JSON 한 줄 (`logback-spring.xml`) |
| 작성 방법 | `AppLog.event(log, "<도메인>.<동작>").with(키, 값).info(메시지)` 만 사용 |
| traceId | Micrometer Tracing이 MDC에 넣고, 없으면 `RequestLogFilter`가 만든다. 응답 `meta.traceId`로 나간다 |
| 비동기 전파 | `aiExecutor`에 `ContextPropagatingTaskDecorator`. 새 스레드풀을 만들면 같이 붙인다 |
| 요청 로그 | 종료 시 1줄(`http.request.done`). 시작 로그 없음, `/actuator` 제외 |
| 금지 | 본문·토큰·개인정보, 문자열 접합 로그, 4xx를 ERROR로 |

## 4. 앱 공통 계층

| 위치 | 역할 |
|---|---|
| `shared/api/httpClient.ts` | 유일한 HTTP 진입점. 봉투를 여기서만 벗긴다. 타임아웃 10초 |
| `shared/api/ApiError.ts` | 모든 실패를 이 타입으로. 분기는 `code`로 하고 문자열 비교 금지 |
| `shared/theme/tokens.ts` | 디자인 토큰의 진실. 의미 토큰만 컴포넌트에서 참조 |
| `shared/ui/` | Button, Card 등 공용 컴포넌트. 화면 전용은 `features/<x>/ui` |
| `features/<x>/api` | 엔드포인트 함수. URL은 여기에만 |
| `features/<x>/hooks` | TanStack Query 훅과 쿼리 키 팩토리 |

## 5. 검증 하네스

| 시점 | 무엇 |
|---|---|
| 파일 수정 직후 | `compileJava compileTestJava` (Claude hook) |
| 작업 종료 전 | 단위 테스트 + ArchUnit, **docs 미갱신 경고** (Claude hook) |
| commit | spotlessApply -> compile -> ArchUnit -> gitleaks (`.githooks/pre-commit`) |
| push | 단위 테스트 전체 |

ArchUnit 10규칙이 계층 의존 방향(`controller -> service -> repository -> domain`), **`domain`에 엔티티만 두는 규칙**,
도메인 간 직접 참조 금지, 순수 계산 클래스의 모양을 강제한다. 포트 구현체는 `port/<기술>/`에 두고 이 어댑터만
외부 기술 격리 검사에서 빠진다(`ArchitectureTest` 클래스 주석).
