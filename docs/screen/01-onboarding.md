## 1. 목적
앱 첫 진입. 제품을 한 문장으로 설명하고 시작 또는 로그인으로 보낸다.

## 2. 진입 / 이탈
- 진입: 앱 최초 실행, 로그아웃 직후.
- 이탈: "무료로 시작하기" -> 02 홈 / "이미 계정이 있어요" -> 로그인(**미정**).
- 온보딩 완료 후 재진입 없음. 완료 여부는 로컬 플래그로 판단.

## 3. 화면 구성

## 4. 동작
- `dots`가 3개 = 슬라이드 3장 전제. 2·3번째 슬라이드는 시안에 없음(**미정**).
- 좌우 스와이프로 슬라이드 이동, 마지막 슬라이드에서만 CTA 활성화 여부는 미정 -> 기본은 **모든 슬라이드에서 CTA 노출**.
- 보조 링크는 텍스트 버튼. 터치 타깃 44px 확보(`ui-fundamentals`).

## 5. 상태
- 로딩: 없음. 정적 화면.
- 빈: 해당 없음.
- 에러: 없음(네트워크 불필요). 시작 버튼 이후의 실패는 다음 화면 책임.
- 권한: 알림 권한 요청 시점은 여기 아님 -> 10 마이페이지 리마인더 설정에서.

## 6. 데이터
- 서버 호출 없음. 로컬 `onboarding_done` 플래그만 기록.

## 7. 미정
- 슬라이드 2·3번 내용
- 로그인 화면 전체(소셜 로그인 종류 포함) -> `spring-auth`
- 비회원 체험 허용 여부. 허용하면 02부터 로그인 없이 진입해야 함
