## 4. 동작
- `dots`가 3개 = 슬라이드 3장 전제. 2·3번째 슬라이드는 시안에 없음(**미정**).
- 좌우 스와이프로 슬라이드 이동, 마지막 슬라이드에서만 CTA 활성화 여부는 미정 -> 기본은 **모든 슬라이드에서 CTA 노출**.
- 보조 링크는 텍스트 버튼. 터치 타깃 44px 확보(`ui-fundamentals`).

## 7. 미정

- RN에서 유리 CTA를 어떻게 낼지 - `expo-blur`의 `BlurView`로 흐림은 되지만
  모서리 빛 반사선(`mask-composite`)과 가장자리 굴절은 그대로 옮길 수 없다. 근사치를 만들지 말지 미정
- 슬라이드 2·3번 내용
- 로그인 화면 전체(소셜 로그인 종류 포함) -> `spring-auth`
- 비회원 체험 허용 여부. 허용하면 02부터 로그인 없이 진입해야 함
## 8. 구현 (2026-09-21)

- 화면: `app/app/onboarding.tsx`. 탭바 없음. `app/app/(tabs)/_layout.tsx`가 완료 플래그를 보고 여기로 보낸다
- **히어로를 구름으로 바꿨다(의도된 시안 이탈).** 시안의 `jelly-bowl`(꽃잎 + 젤리)은 더 이상 쓰지 않는다
  - 구름 한 장 = 둥근 바 1 + 원 4개를 같은 색으로 겹친 SVG. 합집합으로 보인다
  - 세 장의 진폭·주기·시작 위상을 전부 다르게 줘서 서로 맞물리지 않게 했다(13s / 9s / 11s)
  - 모양·좌표·타이밍이 `app/src/features/onboarding/ui/CloudHero.tsx` 와 `docs/screen/prototype.html` 에 같은 값으로 있다. **한쪽만 고치지 않는다**
  - 다크에서 구름이 흰 판으로 튀어 `cloud` / `cloudOpacity` 토큰으로 색과 알파를 뺐다. 컴포넌트에 다크 분기는 없다
  - `prefers-reduced-motion` / RN 기본 동작에서 모션이 멈춰도 구름은 그대로 보인다
- 에셋: `app/assets/figma/onboarding-dots.svg`(인디케이터), `sunlight.svg`(공통 배경).
  `jelly-bowl.svg` 는 이제 참조하는 곳이 없다 - 지워도 된다
- 플래그: `app/src/shared/lib/onboarding.ts` (`onboarding_done`, AsyncStorage). 읽는 동안은 화면을 그리지 않아 온보딩이 번쩍이지 않는다
- 시안의 844 고정 좌표를 위아래 여백으로 바꿔 어느 화면 높이에서도 순서가 유지된다
- **CTA "무료로 시작하기"는 반투명 유리다**(`glass-button` 스킬). 앱에서 유일한 유리 요소이며
  프리셋 예외로 기록돼 있다(`presets/muted-sky.md` 5.5장). 버튼 뒤 구름 두 장은 유리가 무엇을 흐리는지
  보이게 하는 배경 도형이다 - 지우면 유리가 그냥 반투명 면이 된다. 흰 구름이 아니라 노을빛으로
  물들인 것은 밝은 배경에서 흰 구름이 묻혀 대비가 사라지기 때문이다
- **유리는 HTML 프로토타입에만 있다.** `backdrop-filter`·`mask-composite`가 RN에 없어
  `app/app/onboarding.tsx`는 아직 solid 버튼이다(7장)
