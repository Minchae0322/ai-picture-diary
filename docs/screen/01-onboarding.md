## 4. 동작
- `dots`가 3개 = 슬라이드 3장 전제. 2·3번째 슬라이드는 시안에 없음(**미정**).
- **슬라이드는 한 장으로 줄였다**(8장). 빈 슬라이드를 지어내지 않는다. `dots`는 시안의 자리만
  유지하는 장식이라 스크린리더에서 숨긴다 - 넘길 것이 없는데 "3장 중 1장"이라 읽으면 거짓말이 된다.
- 보조 링크는 텍스트 버튼. 터치 타깃 44px 확보(`ui-fundamentals`).

## 5. 상태
- 로딩: 없음. 정적 화면.
- 빈: 해당 없음.
- 에러: 없음(네트워크 불필요). 시작 버튼 이후의 실패는 다음 화면 책임.
- 권한: 알림 권한 요청 시점은 여기 아님 -> 10 마이페이지 리마인더 설정에서.

## 8. 구현 (2026-10-05)

- 화면: `app/app/onboarding.tsx` · 완료 플래그: `app/src/features/onboarding/useOnboarding.ts`(AsyncStorage)
- 진입 판단은 홈(`(tabs)/index.tsx`)이 한다. 플래그를 읽기 전에는 로딩을 그리고, 없으면 `/onboarding`으로 보낸다
- **디자인은 muted-sky 프리셋이다**(`CLAUDE.md` 디자인 선언). 배경 바닐라 `#faf4dc`, 서체 SUIT.
  색은 코드(`tokens.ts`)가 진실이고 Figma 시안(복숭아 톤)과 갈라져 있다 - 의도된 이탈이다
- **히어로를 손그림 로고로 바꿨다.** 시안의 `jelly-bowl`은 쓰지 않는다
  - 투명 배경 PNG(2048x2048 RGBA)다
  - 원본 안에서 실제 그림은 x 381~1739, y 317~1589이다(알파 경계 상자 측정값).
    가로의 34%가 투명 여백이고 중심도 오른쪽으로 36px 치우쳐 있어 PNG를 그냥 가운데 두면 그림은 가운데가 아니다
  - **그림 영역을 레이아웃 박스로 삼고** 그 안에 원본을 밀어 넣는다. 투명 여백만 잘리고 보이는 것은 잘리지 않는다
  - 표시 폭 280. 크기는 `ART_WIDTH`(RN) / `--art-w`(HTML) 한 곳만 고친다.
    `OnboardingHero.tsx` 와 `prototype.html` 에 같은 값이 있다 - **한쪽만 고치지 않는다**
  - 히어로 자리는 좌우 -45로 화면 여백을 상쇄해 폰 폭을 다 쓴다. 이게 없으면 그림이 칼럼보다 넓어질 때
    flex 의 auto 마진이 0으로 풀려 왼쪽에 붙고 오른쪽만 잘린다
- 히어로 뒤에 **노트 괘선**(`rule` 토큰, 32px 간격 1px, 좌우 28px 여백, `NotebookLines.tsx`).
  양쪽 다 1px 요소를 간격대로 깐다. 한때 HTML만 `repeating-linear-gradient` 한 줄로 그렸으나
  **브라우저 리샘플링이 1px 선을 몇 줄씩 통째로 떨어뜨려** 실제 요소로 바꿨다.
  로고가 괘선을 거의 다 가려서 종이를 그림보다 위로 72px 더 뺀다
- 바닥에 손그림 띠 `bottom.png`. 원본이 정사각이라 그대로 두면 화면 절반을 먹는다 -
  높이 230으로 자르고 그 안에서 바닥에 붙인다. **절대 위치는 padding box 기준**이라 좌우를 -45로 주면
  폰보다 넓어진다. 0으로 두고 창 높이로 자른다
- 헤드라인의 "오늘의 기분"·"그림일기" 뒤에 **형광펜 띠**를 깔았다.
  띠는 `#7c5445`(`highlight`), 그 위 글자는 **배경과 같은 바닐라** `#faf4dc`(`highlightText`).
  글자가 파인 것처럼 보인다. 대비 5.93:1.
  **글자색이 배경과 같아 띠가 획을 빠짐없이 덮어야 한다** - 띠 밖으로 나간 획은 배경에 묻혀 사라진다.
  띠가 어둡고 글자가 밝은 조합이라 다크에서도 같은 값이 통한다 - 다크용 값을 따로 두지 않는다
- **띠 높이는 글자 잉크에 맞춘다.** 덮는 것이 조건이므로 줄일 수 있는 바닥은 잉크 높이다.
  - 세로 `padding` 으로는 못 줄인다. padding 은 더하기만 되고, 배경이 깔리는 인라인 박스는 이미
    폰트의 ascent+descent = (988+260)/1000 = **1.248em** 이다
  - 그래서 HTML 은 배경을 `linear-gradient` 로 그려 `background-size` 로 높이를 em 으로 직접 준다
  - SUIT-Heavy 의 이 한글들 잉크는 **baseline 기준 -0.093em ~ 0.821em, 높이 0.914em**
    (CFF charstring 을 직접 읽어 잰 값. CID 폰트라 FDSelect/FDArray 로 글리프별 로컬 subr 을 찾아야 나온다)
  - 띠는 **-0.130em ~ 0.870em(1em)**. 위 1.7px / 아래 1.3px 여유를 남기고 획을 다 덮는다(34px 기준)
  - 결과: 띠 **45.2px -> 34px**, 위아래 줄 사이 틈 **4.2px -> 15.3px**
  - **RN 은 이 값을 따라오지 못한다.** 중첩 `Text` 의 `backgroundColor` 는 줄 높이를 따라 칠해져
    띠 높이를 따로 줄 수단이 없다. 맞추려면 띠를 측정된 글자 폭 위에 절대 배치한 `View` 로 그려야 하는데
    깨지기 쉬워 두지 않았다. **의도된 미해결 차이다**
- **이모지는 쓰지 않는다.** 아이콘은 `src/shared/ui/Icon.tsx` 의 SVG다(`.githooks/no-emoji.js` 가 커밋에서 막는다).
  장식 이모지(인사말 사탕, 커뮤니티 아바타, Plus 왕관)도 전부 뺐다 - 아바타는 닉네임 첫 글자,
  Plus 는 글자 배지다. 아바타가 글자가 되며 날씨 색 위 대비가 필요해져 `weatherInk` 토큰을 추가했다
  (날씨 6색 전부 4.5:1 통과, 최악은 비 `#8fa9c8` 위 5.19:1)
- **CTA 의 유리 질감은 HTML 프로토타입에만 있다.** `backdrop-filter`·`mask-composite`가 RN에 없어
  `onboarding.tsx` 의 주 버튼은 solid 다(`glass-button` 스킬, `presets/muted-sky.md` 5.5장의 예외 기록)
- **미해결: "이미 계정이 있어요"의 대비.** 이 보조 링크는 바닥에서 56~100px 자리에 있고
  뒤로 `bottom.png` 의 가는 갈색 선이 지나간다. 선이 이 구간 픽셀의 **7%** 를 덮어,
  선이 글자를 가로지르는 자리에서 대비가 **1.0:1** 까지 떨어진다(실제 픽셀 측정).
  - **색만 바꿔서는 못 고친다.** 배경이 밝은 파랑과 진한 갈색 두 톤이라 어떤 단색도 한쪽에서 무너진다:
    `#4e6375` 1.06, `#253544` 2.13, 바닐라 1.33, 코코아 1.11 - 넷 다 4.5:1 실패
  - 글자만 남기기로 했으므로(디자인 결정), 남은 방법은 **띠를 링크 아래에서 끊는 것**이다.
    `bottomArt` 높이를 230 -> 150 으로 줄이면 링크가 바닐라 배경 위로 올라와 현재 색 그대로 **5.66:1** 로 통과한다
  - CTA 가 멀쩡한 이유는 유리의 `blur(3px)` 가 그 선을 녹이고 있기 때문이다
- 확정되어 7장에서 뺀 것: 슬라이드 2·3번 - 시안에 없어 한 장으로 줄였다
- "이미 계정이 있어요"는 이제 11 로그인으로 간다. 다만 그 화면의 버튼들이 아직 인증 없이 홈으로 보낸다
