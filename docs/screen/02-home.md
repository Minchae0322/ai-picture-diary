# 02 홈 · 오늘 기록 전

> 시안: [8:28](https://www.figma.com/design/zbYEQIRk1ttPOFzojh2hcL/AI-%25EA%25B0%2590%25EC%25A0%2595-%25EB%2582%25A0%25EC%2594%25A8%25EC%259D%25BC%25EA%25B8%25B0---Web-App-Sketch?node-id=8-28) · 탭: 홈 · 갱신: 2026-09-21

## 1. 목적
오늘의 한 줄을 받는 화면. 이 앱의 핵심 입력 지점이다.

## 2. 진입 / 이탈
- 진입: 앱 실행 기본 화면, 탭바 "홈".
- 이탈: 기록 전송 -> 03 AI 생성 중 / 최근 기록 탭 -> 과거 상세(**미정**).
- 오늘 기록이 이미 있으면 이 화면 대신 **04 결과 화면**을 보여준다(시안에 "오늘 기록 전"이라 명시).

## 3. 화면 구성
| 순서 | 요소 | 시안 레이어 | 내용 |
|---|---|---|---|
| 1 | 날짜 | `8:32` | "2026년 8월 24일 월요일" |
| 2 | 인사 | `8:33` | "안녕하세요, {닉네임}님" |
| 3 | 연속 기록 배지 | `streak` | "14일 연속" |
| 4 | 빈 카드 | `card` + `empty-canvas` | "아직 오늘의 기분이 없어요" / "AI 그림 영역" 플레이스홀더 |
| 5 | 입력 | `input` + `send` | placeholder "오늘 어땠나요?", 전송 버튼 "기록" |
| 6 | 빠른 감정 칩 | `quick-chips` | 맑음 / 구름조금 / 흐림 / 비 |
| 7 | 최근 기록 | `recent` | 8/23 햇살 가득, 8/22 비 오는 날, 8/21 설레는 밤 |
| 8 | 탭바 | `TabBar` | 홈 활성 |

## 4. 동작
- 입력 비어 있으면 "기록" 비활성. 본문 최대 길이는 **미정**.
- 빠른 감정 칩: 탭하면 감정을 선택(단일). 본문 없이 칩만으로 기록 가능한지 **미정** -> 기본은 **본문 필수, 칩은 보조 힌트**.
- "기록" 누르면 즉시 03으로 전환. 낙관적 전환이며 실패 시 입력값을 복원한다.
- 최근 기록은 3건 고정. 더보기 동선은 05 캘린더.

## 5. 상태
- 로딩: 최초 진입 시 최근 기록·연속일 조회 -> 스켈레톤 3줄.
- 빈: 최근 기록 0건이면 섹션 자체를 숨긴다(빈 목록 노출 금지). 연속 0일이면 배지 숨김.
- 에러: 조회 실패해도 **입력은 살려 둔다**. 상단 카드만 재시도 버튼으로 대체.
- 오프라인: 입력은 받고 로컬 큐에 넣는다(10의 "로컬 우선 저장" 문구 근거). 동기화 규칙 **미정**.

## 6. 데이터
- 조회: 오늘 기록 유무, 연속 기록 일수, 최근 기록 3건.
- 전송: 본문 + 선택 감정 + 작성 시각(로컬 타임존).
- 날짜 경계: "오늘"의 기준 시각 **미정**(07 뱃지의 "04시 기록"과 충돌 가능).

## 7. 미정

- 과거 날짜 소급 기록 허용 여부
- 오프라인 작성 큐와 동기화 충돌 규칙

## 8. 구현 (2026-09-21)

- 화면: `app/app/(tabs)/index.tsx` + `app/src/features/diary/ui/DiaryComposer.tsx`
- API: `POST /api/v1/diaries`, `GET /api/v1/diaries/today`, `GET /api/v1/diaries?size=3`
- 확정되어 3장으로 올린 것: 하루 1건, 본문 1~500자, 감정 9종, 빠른 감정 칩은 힌트일 뿐 AI 판정을 대체하지 않음
- 아직: 오프라인 작성 큐

### 2026-10-20 인사말과 그림 자리
- **인사말이 "님" 한 글자만 둘째 줄에 남겼다.** 닉네임에 띄어쓰기가 들어가면("말랑한 구름이")
  그 자리에서 줄이 갈린다. 줄을 우리가 먼저 나눈다 - `안녕하세요,` / `{닉네임}님` 두 줄 고정.
  긴 닉네임은 둘째 줄에서 말줄임(`numberOfLines={2}`). 어떤 닉네임이 와도 머리 높이가 같다.
- **빈 그림 자리의 물음표를 캐릭터로 바꿨다.** 앱에서 가장 크고 가장 눈에 띄는 빈 칸인데
  기호 하나만 두면 차갑다. `SOSO` 를 투명도 0.35 로 올린다 - 더 진하면 "이게 내 그림인가"로 읽힌다.

## 9. 구현 (2026-09-22)

- 연속 기록 배지: `GET /api/v1/diaries/overview`의 `streakDays`. 0일이면 배지를 숨긴다. 계산은 `StreakCalculator` 한 곳(02·06·10이 같은 값)
- 인사말 닉네임: `GET /api/v1/profile`. 인증이 없어 프로필은 첫 조회에 만들어지고, 닉네임은 `NicknameGenerator`가 "말랑한 젤리곰"처럼 무작위로 붙인다
- 최근 기록 탭 -> `app/app/diary/[id].tsx`(04 과거 날짜 모드). 7장에서 뺐다
- 04 결과에 "공유" 추가 -> 08 피드

## 10. 구현 (2026-10-19) - 날씨에서 감정으로

- 빈 카드 문구가 "아직 오늘의 날씨가 없어요" -> **"아직 오늘의 기분이 없어요"**
- 빠른 감정 칩이 6종 한 줄 줄바꿈에서 **9종 가로 스크롤**로 바뀌었다. 한 화면에 셋이 들어가고
  넷째가 조금 걸치는 폭(`VISIBLE = 3.25`)이다 - 걸쳐 보이는 것이 "더 있다"는 유일한 신호다
- 칩 안에 감정 캐릭터 그림이 들어간다(`EmotionFace`). 색점은 뗐다 - 과일 색은 빨강이 셋이라 뜻을 나르지 못한다
- 칩을 고르면 그 아래에 **감정 세기 게이지**(`EmotionGauge`, -2 ~ +2)가 열린다.
  감정마다 고를 수 있는 쪽이 다르다(행복은 +쪽만, 무난함은 세기가 없다). 감정을 바꾸면 0으로 돌아간다
- 최근 기록 카드의 썸네일이 날씨 아이콘에서 감정 캐릭터로(78px 안에 58). "더보기"(-> 05 캘린더)를 붙였다.
  날씨 시절의 색 그라디언트는 걷어냈다 - 면은 `faceBg` 단색이고 경계는 테두리가 잡는다
- 세기 값은 **아직 서버로 보내지 않는다.** `userHint` 만 전송한다 - 세기를 받을 필드가 API 에 없다
