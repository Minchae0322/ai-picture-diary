# 03 AI 생성 중

> 시안: [8:91](https://www.figma.com/design/zbYEQIRk1ttPOFzojh2hcL/AI-%25EA%25B0%2590%25EC%25A0%2595-%25EB%2582%25A0%25EC%2594%25A8%25EC%259D%25BC%25EA%25B8%25B0---Web-App-Sketch?node-id=8-91) · 탭: 홈 흐름 · 갱신: 2026-09-21

## 1. 목적
기록 전송 후 AI가 감정 분석 + 이미지 생성을 하는 동안의 대기 화면.

## 2. 진입 / 이탈
- 진입: 02에서 "기록" 전송 직후.
- 이탈: 성공 -> 04 결과 / 실패 -> 02로 복귀하며 에러 안내.
- 뒤로가기로 빠져나갈 수 있는지 **미정** -> 기본은 **허용, 생성은 백그라운드 계속**.

## 3. 화면 구성
| 순서 | 요소 | 시안 레이어 | 내용 |
|---|---|---|---|
| 1 | 딤 배경 | `dim` | 02 위에 덮는 오버레이 |
| 2 | 입력 원문 | `8:9x` 카드 | 방금 쓴 한 줄을 그대로 보여줌 |
| 3 | 로더 | `loader` | 진행 인디케이터 |
| 4 | 진행 문구 | - | "AI가 오늘을 그리는 중..." / "감정 분석 완료 · 이미지 생성 …" |
| 5 | 탭바 | `TabBar` | 노출되나 딤 아래. 조작 가능 여부 **미정** |

## 4. 동작
- 2단계 진행: ① 감정 분석 ② 이미지 생성. 문구가 단계에 따라 바뀐다.
- 단계 전환은 서버가 알려주는 값으로만 바꾼다. 시간 기반 가짜 진행 금지.
- 최소 노출 시간을 두어 깜빡임을 막는다(권장 800ms).

## 5. 상태
- 로딩: 이 화면 자체가 로딩 상태.
- 타임아웃: 상한 필요(**미정**, 권장 이미지 60초). 초과 시 "나중에 알려드릴게요"로 전환하고 백그라운드 처리.
- 에러: 분석 실패 / 이미지 실패를 구분한다. 이미지만 실패하면 **텍스트 결과만이라도 04로 보낸다**.
- 부적절 입력 차단(모더레이션) 시 문구가 다르다 -> **미정**.

## 6. 데이터
- 생성 작업 id로 폴링 또는 스트리밍. 방식 **미정** -> `llm-integration`.
- 실패 시 재시도는 사용자 명시 행동으로만. 자동 재시도 금지(비용).

## 7. 미정

- 진행 단계 표시 - 현재는 단일 문구. 서버가 단계 이벤트를 주지 않는다
- 생성 중 앱 종료 후 복구, 완료 푸시 알림
- 부적절 입력(모더레이션) 차단 문구

## 8. 구현 (2026-09-21)

- 화면: `app/src/features/diary/ui/GeneratingCard.tsx` (홈 탭 안에서 상태로 분기)
- 서버: 저장 커밋 후 `@TransactionalEventListener` + `@Async`, 결과 반영은 REQUIRES_NEW 트랜잭션
- 확정: 자동 재시도 없음, 이미지만 실패하면 DONE으로 04까지 보냄, 재생성 하루 3회
- 폴링: 앱이 `GET /api/v1/diaries/today`를 1초 간격으로 호출. 서버 푸시 아님
