# 04 오늘의 결과 · AI 이미지

> 시안: [9:2](https://www.figma.com/design/zbYEQIRk1ttPOFzojh2hcL/AI-%25EA%25B0%2590%25EC%25A0%2595-%25EB%2582%25A0%25EC%2594%25A8%25EC%259D%25BC%25EA%25B8%25B0---Web-App-Sketch?node-id=9-2) · 탭: 홈 흐름 · 갱신: 2026-09-21

## 1. 목적
생성된 그림과 감정 판정을 보여주고 저장·재생성·공유를 고르게 한다.

## 2. 진입 / 이탈
- 진입: 03 완료 직후, 오늘 기록이 이미 있을 때의 홈 탭, 05 캘린더 날짜 탭(과거 날짜도 같은 레이아웃 가정).
- 이탈: 상단 "←" -> 이전 화면 / "공유" -> 08 커뮤니티 또는 OS 공유 시트(**미정**).

## 3. 화면 구성
| 순서 | 요소 | 시안 레이어 | 내용 |
|---|---|---|---|
| 1 | 헤더 | `9:x` | "← 2026.08.24" |
| 2 | 그림 | `AI Artwork (생성 결과)` | 정사각 추정. `ai-tag` "AI generated" 뱃지 필수 |
| 3 | 판정 | `weather` | "맑음 · 기분 +2" |
| 4 | 원문 | - | 사용자가 쓴 한 줄 |
| 5 | AI 코멘트 | - | "AI 코멘트 · 성취감이 느껴지는 …" |
| 6 | 액션 3개 | `actions` | 다시 그리기 / 저장하기 / 공유 |
| 7 | 뱃지 획득 | `card` | "14일 연속 달성! '젤리 14'" |
| 8 | 탭바 | `TabBar` | 홈 활성 |

## 4. 동작
- "저장하기": 일기 확정. 저장 전까지는 임시 상태 -> 이탈 시 폐기 여부 **미정**(기본: 자동 저장하고 버튼은 "완료"로 취급).
- "다시 그리기": 같은 원문으로 이미지만 재생성. 03으로 되돌아간다. **횟수 제한 필요**(비용) - 값 미정.
- "공유": 커뮤니티 공개 = 08 피드에 게시. 게시 시 닉네임·익명 규칙 **미정**.
- 뱃지 카드는 이번 저장으로 새로 얻은 것이 있을 때만 노출. 없으면 영역 자체를 뺀다.
- "AI generated" 표기는 제거 대상이 아니다(생성물 고지).

## 5. 상태
- 로딩: 과거 날짜로 진입 시 이미지 로딩 -> 블러 플레이스홀더.
- 빈: 이미지 실패 + 텍스트만 있는 경우 -> 그림 자리에 "그림을 만들지 못했어요 · 다시 그리기".
- 에러: 저장 실패 시 화면 유지하고 토스트 + 재시도. 화면을 벗어나지 않는다.
- 감정 점수 범위는 06 그래프의 축(-3~+3 추정)과 같은 값을 쓴다.

## 6. 데이터
- 일기 1건 = 원문 + 감정(날씨 enum) + 점수 + AI 코멘트 + 이미지 URL + 생성 메타(모델·프롬프트 버전).
- 이미지 저장·서빙은 `file-upload-storage`. 원본 보존, 목록용 썸네일 별도.

## 7. 미정

- 이미지 내보내기(OS 공유 시트). 현재 "공유"는 커뮤니티 게시로 확정했다
- 임시 저장 개념이 필요한지 - 현재는 생성 직후 자동 저장이라 "저장됨" 비활성 버튼이다

## 8. 구현 (2026-09-21)

- 화면: `app/src/features/diary/ui/DiaryResult.tsx`
- API: `GET /api/v1/diaries/{id}`, `POST /api/v1/diaries/{id}/regenerate`
- 확정: 날씨 6종, 기분 점수 -3~+3, 다시 그리기 하루 3회, "AI generated" 표기 고정, 생성 직후 자동 저장
- 이미지 로드 실패 시 "그림을 만들지 못했어요"로 대체

## 9. 구현 (2026-09-22)

- 액션 3개를 시안대로 배치했다: 다시 그리기 / **저장됨**(자동 저장이라 비활성) / 공유
- "공유" = 08 커뮤니티 게시로 확정. `POST /api/v1/community/posts { diaryId }`. 본문·날씨·닉네임은 서버가 일기와 프로필에서 복사한다
- 뱃지 획득 카드: `GET /api/v1/badges`에서 `earnedAt`이 그날인 뱃지만 보여준다. 판정은 서버가 일기 완료 직후에 한다
- 과거 날짜 모드: `app/app/diary/[id].tsx`. 같은 레이아웃을 쓰되 공유 버튼은 주지 않는다
