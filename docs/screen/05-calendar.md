# 05 감정 캘린더

> 시안: [9:46](https://www.figma.com/design/zbYEQIRk1ttPOFzojh2hcL/AI-%25EA%25B0%2590%25EC%25A0%2595-%25EB%2582%25A0%25EC%2594%25A8%25EC%259D%25BC%25EA%25B8%25B0---Web-App-Sketch?node-id=9-46) · 탭: 캘린더 · 갱신: 2026-09-21

## 1. 목적
한 달치 기록을 날씨 아이콘으로 한눈에 보여주고 과거 기록으로 들어가는 입구.

## 2. 진입 / 이탈
- 진입: 탭바 "캘린더", 02 최근 기록 더보기.
- 이탈: 날짜 탭 -> 04 결과(과거 날짜 모드). 기록 없는 날 탭 -> **미정**(기본: 아무 동작 없음).

## 3. 화면 구성
| 순서 | 요소 | 시안 레이어 | 내용 |
|---|---|---|---|
| 1 | 타이틀 | - | "감정 캘린더" |
| 2 | 월 이동 | - | "‹ 2026년 8월 ›" |
| 3 | 요일 헤더 | `card` | 일~토, 일요일 시작 |
| 4 | 날짜 그리드 | `d1`~`d30` | 날짜 + 날씨 표시 |
| 5 | 월 요약 | `sum-row` | 맑음 12일 / 흐림 6일 / 비 4일 / 무지개 2일 |
| 6 | 탭바 | `TabBar` | 캘린더 활성 |

## 4. 동작
- 주 시작 요일 일요일 고정(시안 기준).
- 좌우 스와이프로 월 이동 지원. 미래 달로는 이동 가능하되 데이터 없음.
- 오늘 날짜는 별도 강조. 기록 없는 날과 미래 날은 시각적으로 구분한다(시안에 없음 -> 정의 필요).
- 요약 수치는 **해당 월 기록 기준**. 합계가 표시 일수와 다를 수 있다(무기록일).

## 5. 상태
- 로딩: 월 단위 조회. 그리드 스켈레톤, 월 이동 시 이전 달 데이터 유지하며 교체.
- 빈: 그 달 기록 0건 -> 그리드는 그대로 두고 요약 자리에 "이 달은 아직 기록이 없어요".
- 에러: 월 조회 실패 -> 요약·그리드 대신 재시도 1개.
- 잠금(10의 "일기 잠금" ON) 상태에서 캘린더가 가려지는지 **미정**.

## 6. 데이터
- 월 조회: 날짜별 (날씨 enum, 기록 id) 목록 + 월 집계.
- 집계는 서버에서 계산해 내려준다. 클라이언트 재계산 금지(06과 값이 갈린다).

## 7. 미정
- 하루 여러 기록일 때 셀에 무엇을 보일지
- 무기록일 탭 동작 (그 날짜로 소급 기록 허용 여부와 연결)
- 연/주 단위 보기 필요 여부
