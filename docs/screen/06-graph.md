# 06 감정 그래프

> 시안: [9:181](https://www.figma.com/design/zbYEQIRk1ttPOFzojh2hcL/AI-%25EA%25B0%2590%25EC%25A0%2595-%25EB%2582%25A0%25EC%2594%25A8%25EC%259D%25BC%25EA%25B8%25B0---Web-App-Sketch?node-id=9-181) · 탭: 그래프 · 갱신: 2026-09-21

## 1. 목적
기분 점수 추이와 요약 지표를 보여준다. "기록이 쌓였다"는 체감을 만드는 화면.

## 2. 진입 / 이탈
- 진입: 탭바 "그래프".
- 이탈: 없음(읽기 전용). 단어 칩 탭 동작 **미정**.

## 3. 화면 구성
| 순서 | 요소 | 시안 레이어 | 내용 |
|---|---|---|---|
| 1 | 기간 세그먼트 | `segment` | 주 / 월 / 년 |
| 2 | 추이 차트 | `card` + `grid` | "8월 기분 추이", 부제 "평균 +1.2 · 지난달보다 0.…" |
| 3 | Y축 | - | +3 / +1 / -1 (범위 -3~+3 추정) |
| 4 | KPI 3개 | `kpi` | 평균 기분 +1.2 / 최고의 날 8/19 / 연속 기록 14일 |
| 5 | 자주 쓴 말 | `words` | 회의 · 산책 · 피곤 · 맛있다 |
| 6 | 탭바 | `TabBar` | 그래프 활성 |

## 4. 동작
- 세그먼트 전환 시 차트·부제·KPI 전부 해당 기간으로 바뀐다. "자주 쓴 말"도 같은 기간 기준.
- 점 탭 시 해당 날짜 상세로 이동할지 **미정**(기본: 툴팁만).
- 무기록일은 선을 끊는다. 0으로 채우지 않는다 - 0은 "보통"이라는 뜻이라 거짓이 된다.
- 차트 규칙은 `dataviz` 참조. 색으로만 의미를 구분하지 않는다.

## 5. 상태
- 로딩: 차트·KPI 스켈레톤.
- 빈: 기록 2건 미만이면 추이선을 그리지 않고 "기록이 3일 이상 쌓이면 추이를 보여드려요".
- 에러: 카드 단위 재시도.
- 접근성: 차트 옆에 텍스트 요약(평균·최고·최저)을 반드시 둔다.

## 6. 데이터
- 기간별 (날짜, 점수) 시계열 + 집계 KPI + 상위 단어 N개.
- 단어 추출 주체(형태소 분석기/LLM)와 불용어 처리 **미정** -> `llm-integration`.
- 연속 기록 일수는 02·10과 **같은 값**이어야 한다. 계산 위치를 한 곳으로 고정한다.

## 7. 미정
- 점수 범위 정의(-3~+3?)와 "평균"의 계산 방식
- 년 보기의 표현(월별 평균 막대?)
- 자주 쓴 말의 개수·정렬 기준·탭 동작
