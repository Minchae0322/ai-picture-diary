## 1. 목적
획득·미획득 뱃지를 보여주며 계속 기록할 이유를 만든다.

## 2. 진입 / 이탈
- 진입: 10 마이페이지의 "뱃지" 통계, 04의 뱃지 획득 카드 탭(**미정**).
- 이탈: 뒤로가기. 뱃지 탭 시 상세 시트 노출 여부 **미정**.

## 4. 동작
- 총 40개 중 12개만 시안에 있음. 나머지 28개 **미정**.
- 잠금 뱃지는 조건은 보이되 아이콘은 가린다(시안의 🔒 표기).
- 획득 판정 시점: 저장 성공 직후 서버가 계산하고 04에서 알린다. 클라이언트 판정 금지.
- "감정 탐험가 · 6종 전부" -> **날씨 enum이 6종이라는 근거.** 04·05의 목록과 맞춰야 한다.

## 5. 상태
- 로딩: 그리드 스켈레톤 12칸.
- 빈: 발생하지 않음("첫 기록" 전에도 잠금 상태로 전부 보인다).
- 에러: 전체 재시도 1개.

## 6. 데이터
- 뱃지 정의는 서버 마스터 데이터. 조건 문구도 서버가 준다(앱 업데이트 없이 추가하기 위함).
- 사용자별: 획득 여부 + 획득 일시.

## 7. 미정
- 나머지 28개 뱃지 정의
- "다음 뱃지" 추천 로직
- 뱃지 상세/공유 화면 유무
- 소급 획득(이미 조건을 넘긴 기존 사용자) 처리
