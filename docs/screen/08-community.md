# 08 커뮤니티

> 시안: [10:79](https://www.figma.com/design/zbYEQIRk1ttPOFzojh2hcL/AI-%25EA%25B0%2590%25EC%25A0%2595-%25EB%2582%25A0%25EC%2594%25A8%25EC%259D%25BC%25EA%25B8%25B0---Web-App-Sketch?node-id=10-79) · 탭: 커뮤니티 · 갱신: 2026-09-21

## 1. 목적
다른 사람의 오늘 날씨를 구경하고 반응한다.

## 2. 진입 / 이탈
- 진입: 탭바 "커뮤니티", 04의 "공유".
- 이탈: FAB "+ 오늘 공유" -> 공유 작성(**미정**) / 카드 탭 -> 상세(**미정**) / 댓글 아이콘 -> 댓글(**미정**).

## 3. 화면 구성
| 순서 | 요소 | 시안 레이어 | 내용 |
|---|---|---|---|
| 1 | 타이틀 | - | "오늘의 날씨 피드" |
| 2 | 필터 | `filters` | 인기 / 최신 / 맑음 / 비 |
| 3 | 피드 카드 | `card` x3 | 닉네임+이모지, 상대 시각, 날씨 칩, 본문, 반응 |
| 4 | 반응 | `reactions` | 좋아요 128 · 댓글 14 · 공유 |
| 5 | FAB | `FAB` | "+ 오늘 공유" |
| 6 | 탭바 | `TabBar` | 커뮤니티 활성 |

## 4. 동작
- 필터는 정렬(인기/최신)과 날씨 필터가 **한 줄에 섞여 있다.** 실제로는 축이 둘이므로 동시 선택 규칙 필요 -> 기본: **정렬 1개 + 날씨 다중**.
- 무한 스크롤. 커서 페이징(`api-design`). 오프셋 쓰지 않는다.
- 좋아요는 낙관적 업데이트, 실패 시 되돌린다. 연타 방지 필요.
- 카드에 **그림이 없다.** 텍스트만 공유하는지 그림도 함께인지 **미정** - 제품 성격이 갈리는 지점.
- 신고·차단 동선이 시안에 없다. UGC에 필수이므로 반드시 추가한다(스토어 심사 항목, `app-store-release`).

## 5. 상태
- 로딩: 카드 스켈레톤 3개. 추가 로드는 하단 인디케이터.
- 빈: 필터 결과 0건 -> "이 날씨의 기록이 아직 없어요" + 필터 해제 버튼.
- 에러: 첫 로드 실패 -> 전체 재시도. 추가 로드 실패 -> 하단에만 재시도.
- 권한: 비로그인 열람 허용 여부 **미정**. 반응·작성은 로그인 필수.

## 6. 데이터
- 목록: 게시글 id, 작성자 표시명, 상대 시각, 날씨, 본문, 좋아요/댓글 수, 내 좋아요 여부.
- 공유 = 04의 일기를 게시글로 복사하는지 참조하는지 **미정**. 원본 수정·삭제 시 동작이 달라진다.

## 7. 미정
- 게시글 상세/댓글 화면 (댓글 도메인 없음. `commentCount`는 항상 0)
- **신고 처리 도구와 차단.** 신고를 받기만 하고 자동 숨김·관리 화면이 없다 - 배포 전 필수
- 익명 공유 선택지. 현재는 프로필 닉네임이 그대로 노출된다
- "인기" 정렬의 시간 감쇠. 현재는 좋아요 누적순이라 오래된 인기 글이 위에 고인다
- 비로그인 열람 허용 여부. 현재는 사용자 헤더가 없으면 401

## 8. 구현 (2026-09-22)

- 화면: `app/app/(tabs)/community.tsx` · 카드 `app/src/features/community/ui/PostCard.tsx` · 필터 `FeedFilters.tsx` · 신고 `ReportSheet.tsx`
- API: `GET/POST /api/v1/community/posts`, `POST|DELETE .../{id}/like`, `POST .../{id}/report`, `DELETE .../{id}`
- 확정되어 7장에서 뺀 것
  - **정렬 1개 + 날씨 다중.** 시안의 한 줄 섞임을 두 축으로 나눴다
  - 정렬 3종: **추천 / 최신 / 인기**. 시안의 인기·최신에 추천을 더했고 기본값이다
  - **공유는 참조가 아니라 복사.** 게시 시점의 본문·날씨·닉네임을 글이 자기 행에 들고 있다. 원본을 고치거나 지워도 피드는 그대로
  - **카드에 그림이 없다** - 시안대로 텍스트만 공유한다
  - 삭제 정책: 내 글만 소프트 삭제. 남의 글은 신고로
- **신고를 카드마다 넣었다.** 시안에 없지만 UGC 배포 필수(`app-store-release`)
- 무한 스크롤은 `FlatList` + 커서 페이징. 정렬을 바꾸면 커서가 무효가 되어 처음부터 다시 읽는다
- **추천 정렬**: 내 오늘 기분과 비슷한 글 먼저. 점수 = 날씨 일치 2 + 기분 1칸 이내 1 + 최근 3일 1
  - 임베딩이 아니라 규칙 점수다. 날씨·점수는 이미 AI 판정을 거친 요약이라 500자 한 줄의 임베딩보다 덜 흔들리고 호출 비용이 0이다(`feed-ranking` 3장)
  - 오늘 기록이 없으면 최신순으로 떨어지고, 앱이 "오늘 한 줄을 남기면..." 안내를 띄운다
  - **다양성**: 상위 10개 중 2개는 다른 날씨를 끌어올린다. 유사도만으로 정렬하면 비 오는 사람에게 비 오는 글만 보인다 - 감정 제품에서 이건 사고다(`feed-ranking` 4장)
    - 재배열일 뿐 페이지의 글 목록은 그대로다. 그래야 커서가 안 깨진다
    - 1등은 밀리지 않는다. 자리를 내주는 건 상위 구간에서 점수가 가장 낮은 글이다
    - 사용자가 날씨를 직접 골랐으면 섞지 않는다 - "비만 보여 줘"에 맑음을 끼워 넣는 건 요청 무시다
- 좋아요는 낙관적 업데이트 후 실패 시 되돌린다. 서버는 멱등이라 연타해도 결과가 같다
- FAB "+ 오늘 공유"는 홈으로 보낸다. 별도 작성 화면을 만들지 않았다 - 공유의 출발점은 04 결과 화면이다
