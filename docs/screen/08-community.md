# 08 커뮤니티

> 시안: [10:79](https://www.figma.com/design/zbYEQIRk1ttPOFzojh2hcL/AI-%25EA%25B0%2590%25EC%25A0%2595-%25EB%2582%25A0%25EC%2594%25A8%25EC%259D%25BC%25EA%25B8%25B0---Web-App-Sketch?node-id=10-79) · 탭: 커뮤니티 · 갱신: 2026-09-21

## 1. 목적
다른 사람의 오늘 날씨를 구경하고 반응한다.

## 2. 진입 / 이탈
- 진입: 탭바 "커뮤니티", 04의 "공유".
- 이탈: FAB "+ 오늘 공유" -> 공유 작성(**미정**) / 카드 탭 -> 상세(**미정**) / 💬 -> 댓글(**미정**).

## 3. 화면 구성
| 순서 | 요소 | 시안 레이어 | 내용 |
|---|---|---|---|
| 1 | 타이틀 | - | "오늘의 날씨 피드" |
| 2 | 필터 | `filters` | 인기 / 최신 / 맑음 / 비 |
| 3 | 피드 카드 | `card` x3 | 닉네임+이모지, 상대 시각, 날씨 칩, 본문, 반응 |
| 4 | 반응 | `reactions` | ♥ 128 · 💬 14 · ↗ 공유 |
| 5 | FAB | `FAB` | "+ 오늘 공유" |
| 6 | 탭바 | `TabBar` | 커뮤니티 활성 |

## 4. 동작
- 필터는 정렬(인기/최신)과 날씨 필터가 **한 줄에 섞여 있다.** 실제로는 축이 둘이므로 동시 선택 규칙 필요 -> 기본: **정렬 1개 + 날씨 다중**.
- 무한 스크롤. 커서 페이징(`api-design`). 오프셋 쓰지 않는다.
- ♥는 낙관적 업데이트, 실패 시 되돌린다. 연타 방지 필요.
- 카드에 **그림이 없다.** 텍스트만 공유하는지 그림도 함께인지 **미정** - 제품 성격이 갈리는 지점.
- 신고·차단 동선이 시안에 없다. UGC에 필수이므로 반드시 추가한다(스토어 심사 항목, `app-store-release`).

## 5. 상태
- 로딩: 카드 스켈레톤 3개. 추가 로드는 하단 인디케이터.
- 빈: 필터 결과 0건 -> "이 날씨의 기록이 아직 없어요" + 필터 해제 버튼.
- 에러: 첫 로드 실패 -> 전체 재시도. 추가 로드 실패 -> 하단에만 재시도.
- 권한: 비로그인 열람 허용 여부 **미정**. 반응·작성은 로그인 필수.

## 6. 데이터
- 목록: 게시글 id, 작성자 표시명, 상대 시각, 날씨, 본문, 좋아요/댓글 수, 내 좋아요 여부.
- 공유 = 04의 일기를 게시글로 복사하는지 참조하는지 **미정**. 원본 수정·삭제 시 동작이 달라진다.

## 7. 미정
- 게시글 상세/댓글/작성 화면
- 신고·차단·삭제 정책과 관리 도구
- 익명 여부, 닉네임 변경 가능 여부
- "인기" 정렬 기준
