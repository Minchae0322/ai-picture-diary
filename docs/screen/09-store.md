# 09 테마 · 캐릭터 상점 (프리미엄)

> 시안: [11:2](https://www.figma.com/design/zbYEQIRk1ttPOFzojh2hcL/AI-%25EA%25B0%2590%25EC%25A0%2595-%25EB%2582%25A0%25EC%2594%25A8%25EC%259D%25BC%25EA%25B8%25B0---Web-App-Sketch?node-id=11-2) · 탭: MY 하위 · 갱신: 2026-09-21

## 1. 목적
테마·캐릭터를 고르고 구독(Jelly Plus)으로 유도한다.

## 2. 진입 / 이탈
- 진입: 10 마이페이지 "테마 변경", 잠금 항목 탭.
- 이탈: 배너 "구독" -> 결제(**미정**) / 테마 선택 -> 즉시 적용 후 잔류.

## 3. 화면 구성
| 순서 | 요소 | 시안 레이어 | 내용 |
|---|---|---|---|
| 1 | 타이틀 | - | "꾸미기" |
| 2 | 구독 배너 | `premium-banner` | "Jelly Plus · 모든 테마 · 캐릭터 · 무제한 …" + "구독" |
| 3 | 카테고리 탭 | `store-tabs` | 테마 / 캐릭터 / 배경 / 폰트 |
| 4 | 테마 그리드 | `theme-grid` | Jelly(기본·사용 중), Night Jelly 👑, Mint Soda, Lavender 👑 |
| 5 | 캐릭터 | `characters` | 젤리곰(보유), 별사탕/구름이/새싹 🔒 |
| 6 | 탭바 | `TabBar` | - |

## 4. 동작
- 무료 테마는 탭 즉시 적용. Plus 테마는 구독 유도 시트.
- 적용 중 항목은 "기본 · 사용 중" 라벨로 1개만 표시.
- 카테고리 탭 4개 중 시안은 "테마"만 있다. 배경·폰트 목록 **미정**.
- 캐릭터가 화면 어디에 나오는지 시안에 없다(01 젤리곰 일러스트 추정) -> **미정**.

## 5. 상태
- 로딩: 그리드 스켈레톤. 프리뷰 이미지는 지연 로드.
- 빈: 카테고리에 항목 0개면 탭 자체를 숨긴다.
- 에러: 목록 실패 -> 재시도. 구매·복원 실패는 전용 문구.
- 구독 복원(Restore) 동선 필요. 시안에 없으나 iOS 심사 필수(`app-store-release`).

## 6. 데이터
- 상품 마스터(무료/Plus 구분, 프리뷰 URL)는 서버. 가격·결제는 스토어 인앱결제.
- 구독 상태는 영수증 검증 결과를 서버가 보관. 클라이언트 플래그를 신뢰하지 않는다.

## 7. 미정
- 구독 상품 구성(월/연), 가격, 무료 체험
- Plus 범위: 테마 외 "무제한 …"이 무엇인지 (재생성 횟수로 추정)
- 개별 구매 가능 여부 (구독 전용인지)
- 배경·폰트 카테고리 내용
